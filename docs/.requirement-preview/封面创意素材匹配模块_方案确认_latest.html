封面创意素材匹配模块

把创作者已有图片、截图或内容想法，转化为 3 个可比较、可选择、可继续微调的封面创意方案。

需求目标

让创作者在发布内容前，通过上传素材或输入内容想法，快速获得 3 个围绕点击心理、图像题材、标题方向和构图建议组成的封面创意方案；同时把内部规则、复盘和写回能力收束为后台支撑，不再作为主工作台的第一入口。

本次范围

  • 在创作者主工作台前置封面创意素材匹配入口，支持内容主题、目标平台、内容目标、素材类型、素材说明和本地参考图输入。
  • 支持多张本地参考图或截图作为内容理解素材，并明确区分可直接做封面的图片与仅用于理解内容的参考素材。
  • 基于内容主题、素材特征和目标平台，输出 3 个封面创意方案，每个方案包含方案名、推荐图像题材、标题方向、构图建议、点击理由和风险提醒。
  • 对每个方案给出当前素材适用判断：可直接使用、建议裁切优化、建议补图、仅作内容参考。
  • 用户可选择一个方案进入二轮微调，并通过一句反馈调整标题风格、图像方向或构图重点。
  • 真实案例 real-002、real-003 作为本轮验证样例，用于检查输出是否比通用建议更具体、更贴合素材。

页面与功能拆解

页面/区块 入口 功能 核心交互 输出结果 状态/边界
创作者主工作台首页主入口封面创意开始区用户输入内容主题、选择目标平台、填写内容目标，并上传一张或多张本地参考图。形成一次封面创意任务，进入素材理解和方案生成流程。内容主题或素材至少提供一项；缺少内容目标时使用默认目标：提升点击意愿。
素材理解提示系统根据素材类型展示当前图片用途判断，提示图片可作为封面候选、内容参考或需要补充说明。用户在生成前知道当前素材是否足以支持封面方案。当前阶段只做浏览器本地预览，不上传服务器；无法识别图片内容时要求用户补充素材描述。
首轮方案结果区生成封面创意方案三方案输出系统一次输出 3 个差异化方向，分别对应不同点击心理和图像题材。展示 3 张方向卡，方便用户比较、选择和继续微调。每轮固定 3 个方案；不在本轮直接生成最终图片，不承诺真实点击率提升数值。
方案内容结构每个方案展示方案名、适合的封面图、素材适用判断、标题方向、构图建议、点击理由和风险提醒。用户可以判断哪个方案更适合当前内容，而不是只看到泛化标题。标题是方向建议，不作为最终发布文案强制写死；风险提醒需要避免夸大和与内容不符。
二轮微调区选择方案后继续调整一句反馈微调用户选择一个方案，并输入一句反馈，例如更高级、更有食欲、更像教程、更突出晚霞情绪。系统围绕已选方案调整标题风格、图像题材或构图重点。二轮微调只基于已选方案进行收束，不重新生成完全无关的三套方向。
真实案例区加载真实案例案例载入验证用户可加载 real-002 或 real-003，将案例字段带入主工作台复跑。验证模块是否能从真实素材中生成更具体的封面创意方案。真实案例用于验证产品链路，不作为普通用户必须理解的后台流程。
后台支撑区低频维护入口规则与复盘沉淀保留规则复跑、优选标题写回和案例记录能力，但从主体验中弱化。产品前台保持简单，后台继续支持规则迭代和样例沉淀。后台支撑不作为新用户第一屏核心内容；不新增复杂运营后台。
