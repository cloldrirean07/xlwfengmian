# Docs

This folder stores documentation that should live with the codebase.

## Subfolders

- `product/`
  Implementation-facing product docs, scoped MVP decisions, API notes, and feature records.
- `research/`
  Rule experiments, case analysis outputs, evaluation summaries, and structured findings.
- `prd/`
  Formal requirement documents, versioned feature scopes, and release definitions.
- `architecture/`
  System structure notes, data flow decisions, API contracts, and implementation design records.
- `operations/`
  Runbooks, release notes, sync conventions, and maintenance records.
