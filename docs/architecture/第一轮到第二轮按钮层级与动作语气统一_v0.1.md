# 第一轮到第二轮按钮层级与动作语气统一_v0.1

## 1. 这轮为什么继续做 UI

在已经完成：

- 第一轮到第二轮的流程衔接
- 第二轮继续优化入口
- 第一轮到第二轮的视觉节奏统一

之后，主链路已经越来越完整。

但还有一个比较细、却很影响产品感的问题：

- 第一轮卡片 CTA 的动作说法
- 第二轮反馈提交按钮的动作说法
- 第二轮结果页继续优化入口的动作说法

这些按钮虽然都能用，但它们在语气上还不完全像同一套产品里的连续动作。

更直白一点说：

- 有的在说“进入”
- 有的在说“继续优化”
- 有的在说“做第二轮”

这会让用户在不同阶段感受到的动作语言不够统一。

所以这轮优化的重点不是新增能力，而是统一“下一步动作”怎么被表达。

## 2. 这轮要解决的问题

本轮主要解决 2 个问题：

1. 从第一轮到第二轮，哪些按钮才是真正的主动作
2. 这些主动作是否在语气上形成了一条连续链路

换句话说，本轮优化的是：

- 按钮主次层级
- CTA 文案口径

## 3. 设计原则

本轮延续轻量优化策略：

- 不改业务逻辑
- 不改状态结构
- 不改交互链路

只做两件事：

1. 让真正推进流程的动作更像主按钮
2. 让不同阶段的主动作说同一种语言

这里统一的原则是：

- 进入下一步时，尽量使用“继续填写 / 生成结果 / 下一轮反馈”这类明确动作语句
- 避免同一链路里同时混用“选择 / 进入 / 优化 / 继续做”而缺少规律

## 4. 本轮具体改动

## 4.1 第一轮卡片 CTA 区分主次

在 `renderCards` 中：

- 未选中卡片仍保留次级按钮样式
- 已选中卡片改成主动作按钮样式

具体文案调整为：

### 未选中卡

- `用这张进入第二轮`

这比“选择这张做第二轮”更明确地表达了：

- 这一步不是只做选择
- 而是在用这张卡推进到下一阶段

### 已选中卡

- `继续填写第二轮反馈`

这比“已选中，继续二轮优化”更具体，因为它直接告诉用户：

- 现在该去填反馈
- 下一步不是泛泛地“优化”，而是去完成二轮输入

## 4.2 第二轮提交按钮统一成结果导向

在 `index.html` 中，原来的：

- `进入第二轮优化`

调整为：

- `生成第二轮优化结果`

原因是：

- 用户已经在第二轮表单里了
- 这一步不是“进入”第二轮
- 而是提交当前反馈，生成本轮结果

这让按钮动作与当前页面状态更一致。

## 4.3 第二轮结果页继续优化入口统一成填写动作

在 `renderRefinementResult` 中，继续优化按钮由：

- `继续优化这一方向`

调整为：

- `继续填写下一轮反馈`

这样它与上一层“继续填写第二轮反馈”形成统一节奏：

- 当前轮：继续填写第二轮反馈
- 下一轮：继续填写下一轮反馈

用户会更容易理解：

- 结果页不是终点
- 下一步依然是回到反馈输入，只是进入下一轮

## 4.4 为选中卡 CTA 提升主按钮层级

在样式层新增：

- `card-primary-cta`

并让它：

- 保持主按钮配色
- 占满卡片宽度
- 与原有次级按钮拥有一致尺寸节奏

这样第一轮卡片在状态上会更清楚：

- 普通卡是待选项
- 已选卡的 CTA 是当前主动作

## 7. 这轮带来的价值

这一轮之后，用户在第一轮到第二轮之间看到的按钮，会更像一条连续动作链，而不是每一段都换一种说法。

最直接的提升是：

- 主动作更清楚
- 已选卡状态更像“当前该点的下一步”
- 第二轮表单提交动作更符合当前阶段
- 结果页继续优化入口更像连续迭代动作

## 8. 对后续 UI 的意义

到这一步，当前 UI 已经开始从：

- 先补结构
- 再补流程
- 再补节奏

进一步进入：

- 统一动作语言
- 统一按钮主次表达

所以下一步如果继续推进，更值得看的将是：

1. 是否要进一步统一工作区按钮与主链路按钮的语气
2. 是否要给不同层级动作建立更稳定的按钮规范
3. 等真实案例和使用频率再多一些后，再进入更完整的系统级视觉统一
