# 二轮解释验证记录导出 v0.1

## 本次目的

把已经接入的二轮反馈映射解释，进一步沉淀为一份可复核、可编辑、可回填的 Obsidian 验证草稿。

## 本次实现

### 1. 新增二轮解释 markdown 构建器

- `src/domain/refinement/buildRefinementExplanationMarkdown.js`

从现有 `run:case` 结果中抽取：

- 首轮/二轮规则版本
- 选中卡片与用户原话反馈
- 命中的负向/正向映射
- 命中关键词
- 二轮解释摘要
- 人工验证区与后续动作

### 2. 新增 Obsidian 包装器

- `src/domain/refinement/buildObsidianRefinementExplanationRecord.js`

把上面的代码侧解释底稿包装成可继续编辑的 Obsidian 草稿。

### 3. 新增导出脚本

- `scripts/export-obsidian-refinement-explanation.js`
- `package.json` 新增：
  - `export:obsidian-refinement-explanation`

导出目标目录：

- `05_验证与实验/二轮解释验证记录/已生成记录`

## 为什么这一步重要

- 二轮解释终于进入验证目录，而不是只停留在页面里
- 你后续可以直接在 Obsidian 里补“映射是否合理”“是否误判”“是否要修规则”
- 这为后面的“误判样本 -> 规则修订任务”打下记录基础

## 当前边界

- 目前导出来源仍然依赖 `run:case` 的结果文件
- 还没有把真实用户线上操作直接导出到这份记录里

## 下一步建议

1. 把“二轮解释验证记录”与“误判样本导出”自动关联。
2. 增加一个汇总报表，看哪些映射 ID 最容易被判为不合理。
3. 后续把真实交互产生的二轮记录也接到这套导出链路。
