# 规则修订任务单生成 v0.1

## 本次目的

把“已确认要导出的误判样本”继续推进成规则修订任务单，让验证结果真正转化为可执行的规则修改动作。

## 本次实现

### 1. 新增任务单报告

- `src/domain/refinement/buildRuleRevisionTaskSheetReport.js`
- `src/domain/refinement/buildRuleRevisionTaskSheetMarkdown.js`

当前会根据已导出的误判样本，按以下维度自动归并：

- `suggestedMappingId`
- `suggestedKeyword`
- `fallbackAdjustment`

并生成：

- 任务标题
- 优先级
- 关联 case
- 原系统映射
- 实际问题归纳
- 建议关键词 / 映射 / 兜底策略

### 2. 新增 Obsidian 包装器

- `src/domain/refinement/buildObsidianRuleRevisionTaskSheetRecord.js`

### 3. 新增脚本

- `report:rule-revision-task-sheet`
- `export:obsidian-rule-revision-task-sheet`

导出目标目录：

- `05_验证与实验/规则修订任务单/已生成记录`

## 为什么这一步重要

- 现在闭环正式从“发现误判”进入“产出修订任务”
- 不再需要你手动把误判样本逐条整理成待办
- 为后续规则版本迭代和复跑验证提供清晰入口

## 当前边界

- 当前仍然依赖上游已有误判样本导出
- 如果没有样本满足导出条件，任务单会是空清单

## 下一步建议

1. 增加 task owner / due date / status 字段。
2. 让修订任务单自动关联到具体规则文件位置。
3. 后续增加“修订后复跑哪些 case”的自动建议。
