# 批量真实案例回填工作单预览与导出 v0.1

## 本次目标

把已经存在的：

- 批量字段校验摘要
- 批量推荐动作
- 逐条下一步任务

继续收口成一份真正可执行、可导出、可沉淀到 Obsidian 的批量回填工作单。

## 为什么这一步重要

如果前一阶段只停在页面里展示：

- 缺什么
- 先补什么

那它还是偏“提示型 UI”。

把这些信息进一步整理成一份工作单后，产品就更接近真实工作流：

1. 先准备一批真实案例
2. 看批量质量与优先动作
3. 生成工作单
4. 导出到 Obsidian 持续回填

这一步的意义在于让产品从“判断器”继续变成“工作台”。

## 设计原则

### 复用已有结果，不重复生成第二套逻辑

本次批量工作单不重新判断字段完整度，也不重新计算优先级。

它直接复用：

- `buildRealCaseBatchValidationSummary`
- `buildRealCaseFillSheet`
- `rankRealCaseFillTasks`

从而把已有结构转成一份可执行底稿。

### 导出结构要同时服务代码与 Obsidian

本次导出不是只写一份 Obsidian Markdown，而是同时保留：

- 代码侧 JSON 底稿
- 代码侧 Markdown 底稿
- Obsidian 草稿
- 导出日志

这样后面才能：

- 回看导出历史
- 对比不同批次
- 继续做导出策略和回填迭代

## 代码结构

### 新增领域层

- `src/domain/cases/buildRealCaseBatchFillWorksheetMarkdown.js`
  - 把批量摘要转成工作单 Markdown
- `src/domain/cases/buildObsidianRealCaseBatchFillWorksheetRecord.js`
  - 把工作单 Markdown 包装成可编辑的 Obsidian 草稿

### 新增应用层

- `src/application/createRealCaseBatchFillObsidianPreview.js`
  - 生成 Obsidian 目标路径与草稿内容
- `src/application/runRealCaseBatchFillPreview.js`

- `src/application/exportRealCaseBatchFillWorksheetToObsidian.js`
  - 导出代码底稿、Obsidian 草稿和日志

- `POST /api/real-case-batch-fill-export`
