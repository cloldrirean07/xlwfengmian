# 复盘看板自动带出正式写回状态_v0.1

## 1. 目标

前一版已经支持：

- 手动点击 `检查正式写回状态`
- 把结果留在复盘面板里

但真实使用里仍有一个多余动作：

- 每次重新生成复盘看板后，还要再点一次状态检查

这次补的是：

- 生成复盘看板时自动带出当前正式写回状态
- 导出安全写回预览后自动刷新正式写回状态

## 2. 当前新增内容

前端交互层：

- `createApp.js`

具体补充：

- `previewBatchReviewDashboard` 时并行读取 `previewBatchReviewManualFormalWriteReadiness`
- `export-manual-review-safe-write` 成功后自动刷新 `latestFormalWriteReadiness`

## 3. 当前页面行为

现在有两种自动更新时机：

1. 生成复盘看板时
   - 页面会直接把当前正式写回状态带进面板

2. 导出建议态/人工态安全写回预览后
   - 页面会顺手刷新正式写回状态

这意味着你后面经常能直接看到：

- 当前是不是还在等人工确认
- 最近对应的是哪份安全写回预览
- 是否已经接近正式写回

## 4. 为什么这一步值得做

这个项目当前重点不是美化页面，而是把真实推进链路压顺。

如果每一步都要额外手点一次“状态检查”，虽然不复杂，但会让验证链条显得更碎，也更容易丢上下文。

所以这次做的是：

- 减少重复动作
- 保持状态连续
- 让复盘看板更像真正的工作面板

## 5. 当前结论

可以把这次补充压缩成一句话：

**复盘看板现在会自动带出正式写回状态，你不需要每次都再手点一次状态检查。**
