# 二轮误判样本自动推进 v0.1

## 本次目的

把“人工复核里勾选应导出误判样本”的判断，真正接入下游误判样本导出链路，而不是只停留在汇总统计里。

## 本次实现

### 1. 新增自动推进报告

- `src/domain/refinement/buildReviewedMisclassifiedExportReport.js`
- `src/domain/refinement/buildReviewedMisclassifiedExportMarkdown.js`

筛选条件：

- `review_status=misclassified`
- `should_export_to_misclassified=yes`

输出内容：

- 原系统映射与原解释
- 人工判断的实际问题
- 建议映射 ID
- 建议关键词
- 建议保留信号
- 兜底策略建议

### 2. 新增 Obsidian 包装器

- `src/domain/refinement/buildObsidianReviewedMisclassifiedExportRecord.js`

### 3. 新增脚本

- `report:reviewed-misclassified`
- `export:obsidian-reviewed-misclassified`

导出目标目录：

- `05_验证与实验/二轮误判样本导出/已生成记录`

## 为什么这一步重要

- 从“人工判断有误判”正式进入“系统自动收集误判样本”
- 为下一步规则修订任务单提供更稳定的输入
- 减少你手动整理误判样本的重复劳动

## 当前边界

- 当前仍然依赖 Obsidian 里的结构化人工复核字段
- 还没有自动把误判样本再推到规则修订任务单

## 下一步建议

1. 把误判样本导出结果接入规则修订任务单生成。
2. 在前端增加“标记为误判并导出”的入口。
3. 后续对误判样本按映射 ID 自动聚类。
