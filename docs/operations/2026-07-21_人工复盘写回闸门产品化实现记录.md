- 依据文档：

## 3. 修改边界

本轮未改动：

- 服务接口
- 真实案例数据结构
- 写回按钮 action id
- 导出、预览、正式写回应用逻辑
- Mock 数据

本轮只修改：

- 复盘看板局部文案
- 人工复盘写回闸门的展示结构
- 写回闸门样式
- 复盘看板建议态写回测试断言
- 更新日志和操作记录

## 4. 文案自检

本轮针对复盘看板核心区域清理：

- 将“这里会显示”调整为面向产品状态的说明
- 将“但你已经可以”调整为无对话痕迹的操作提示
- 将“正式写回不会一开始就开放”调整为闸门规则表达

## 5. 验证口径

本轮应执行：

```bash
node --check public/app/renderers.js
npm test
```

并确认：

- 首页资源可正常返回
- `renderers.js` 包含 `Writeback Gate` 和 `人工复盘写回闸门`
- `styles.css` 包含 `writeback-gate-panel`
- 既有复盘 follow-up action id 未删除
