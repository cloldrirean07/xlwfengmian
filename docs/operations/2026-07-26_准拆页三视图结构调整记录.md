# 准拆页三视图结构调整记录

## 1. 本轮目标

[事实] 按“AI 项目资料”的 PI Engine 维护模式，本轮执行准拆页三视图，不新建第二套前端项目。

[事实] 本轮只调整顶层信息架构和视图路由，保留既有业务按钮、接口调用和导出链路。

## 2. 三视图定义

[事实] 当前前端顶层视图已调整为：

- 创建态：输入准备、方向判断、工作区建议确认、第二轮优化。
- 复盘态：真实案例、批量回填、批次试跑、平台复核，沉淀批次证据。
- 写回态：UI 就绪度、跨批次摩擦点、复盘看板、安全写回与正式写回门禁。

## 3. 本轮调整

[事实] 顶层切换按钮从“创作主线 / 案例维护 / 复盘驾驶舱”调整为“创建态 / 复盘态 / 写回态”。

[事实] 案例证据工作台归入复盘态，写回门禁工作台归入写回态。

[事实] 前端路由映射已同步为：

- `creation` -> `#product-view-creation`
- `review` -> `#product-view-review`
- `writeback` -> `#product-view-writeback`

[事实] 原内部工作组 `cases` 继续保留，作为案例工具组标识，不再作为顶层产品视图。

## 4. 验证结果

[事实] 三视图相关测试已通过：`4 pass / 0 fail`。

[事实] 旧的顶层 `product-view-cases`、`ui-readiness-section`、`data-product-view-target="cases"` 标识已从 `public` 和对应测试断言中清除。

## 5. 后续建议

[推断] 下一步更适合继续做写回态内部的“安全预览、人工确认、正式写回”区域聚合，让写回态从工具集合进一步收敛成单一任务面板。
