# 二轮结果到规则复盘入口闭环记录

- 日期：2026-07-23
- 阶段：PI Engine 维护模式
- 对应 Requirement Spec：二轮结果展示 / 案例复盘与规则沉淀

## 本轮目标

补齐二轮结果成功后的第二个后续去向：

```text
二轮结果 -> 进入案例维护
二轮结果 -> 进入复盘驾驶舱
```

## 事实基线

- 当前已有 `enterCaseReviewWorkspace("#real-case-form")`，用于从二轮结果进入案例维护。
- 当前已有 `enterBatchReviewDashboardWorkspace("#review-dashboard-section")`，用于进入复盘驾驶舱并生成批次复盘看板。
- 因此本轮不新增接口、不新增数据结构，只复用既有复盘入口。

## 实现内容

1. 在二轮结果的“结果沉淀”区新增“进入规则复盘”动作。
2. 将该动作绑定到 `data-refinement-follow-up="review-dashboard"`。
3. 在二轮结果事件分支中复用 `enterBatchReviewDashboardWorkspace("#review-dashboard-section")`。
4. 保留原有“进入案例复盘记录”动作。

## 验收口径

- 二轮结果中同时存在：
  - `进入案例复盘记录`
  - `进入规则复盘`
- `record-case` 仍进入案例维护视图。
- `review-dashboard` 进入复盘驾驶舱并触发现有复盘看板生成链路。
- 不修改服务端接口、不改变首轮方向卡和二轮修订数据结构。
