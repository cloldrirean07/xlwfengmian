## 3. 实现范围

本轮将现有单页首页调整为三个产品工作视图：

- 创作主线：承载输入准备、首轮方向、工作区建议、二轮修订与主链路辅助工具。
- 案例维护：承载真实案例录入、批量维护、回填工作单、批次试跑和平台案例复核。
- 复盘驾驶舱：承载 UI 就绪度、跨批次摩擦点、批次复盘看板和写回相关材料。
