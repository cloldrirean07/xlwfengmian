## 3. 问题判断

准拆页已经支持顶部切换、深链恢复和工作组展开，但顶部视图切换不会写入 URL。用户切换到案例维护或复盘驾驶舱后，刷新或分享链接时无法保留当前产品视图状态。

## 4. 核心改动

- `apps/web/public/index.html`
  - 为创作主线和案例维护补充稳定视图锚点。
  - 保留复盘视图既有 `#ui-readiness-section` 锚点，避免破坏历史引用。

- `apps/web/public/app/createApp.js`
  - 顶部三视图切换时写入对应 hash。
  - hash 恢复时同步展开案例维护或复盘驾驶舱工作组。
  - 保留 `#real-case-form` 和 `#review-dashboard-section` 的特殊深链行为。

- `apps/web/tests/coverAssistantService.test.js`
  - 增加稳定视图锚点、hash 写入和旧复盘锚点保留断言。
