# 正式写回后承接任务下一步提示闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：案例复盘成功后形成规则修订或复跑任务。
- Requirement Spec：批次复盘看板需要包含下一步建议。
- Requirement Spec：用户需要跨多个案例判断重复问题，并决定是否进入规则修订。

## 3. 当前缺口

正式写回后的承接任务已经展示任务类型、执行方式和形成依据，但每条任务没有就地提示后续处理方向。用户能看到任务存在，却仍需要自行判断规则修订任务单和关键样例复跑分别应该如何继续。
