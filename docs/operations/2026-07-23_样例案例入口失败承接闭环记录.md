# 样例案例入口失败承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD：加载结构化样例时只填充输入区字段和素材说明，不覆盖本地上传图片。
- PRD：生成失败或案例读取失败时保留入口，允许继续重试。
- Requirement Spec：失败后的去向应保留已填内容，并在输入区附近提示调整或重试动作。

## 3. 当前缺口

加载结构化样例和运行可用案例入口在读取失败时缺少异常承接。接口失败或案例运行失败后，页面可能停留在进行中提示或无明确反馈状态，用户无法稳定回到可操作区域继续处理。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 样例加载失败 | `apps/web/public/app/createApp.js` | 展示“案例读取失败，请重试”，并回到输入区 |
| 可用案例运行失败 | `apps/web/public/app/createApp.js` | 展示“案例读取失败，请重试”，并回到样例结果区 |
| 本地素材保留 | `apps/web/public/app/createApp.js` | 未调用清除素材逻辑，继续保留已有预览 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加样例入口失败后保留可重试区域的断言 |

## 5. 边界

- 未改变样例数据加载协议
- 未改变样例运行结果渲染结构
- 未新增自动重试能力
- 未覆盖或清除本地上传素材预览

## 6. 验收项

- 加载结构化样例失败时展示可理解的读取失败提示
- 加载结构化样例失败时回到输入区，保留已有输入与素材预览
- 运行可用案例失败时回到样例结果区，保留重试入口
