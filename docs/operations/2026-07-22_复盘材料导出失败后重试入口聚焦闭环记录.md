# 复盘材料导出失败后重试入口聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 5.8：导出失败展示“导出失败，请重试”，复盘内容保留。
- PRD 5.7：复盘材料生成成功后，页面展示导出状态和下一步建议。

## 3. 当前缺口

复盘材料导出失败时，页面已有失败提示，相关复盘结果也没有被清空。但失败后用户视线不会稳定回到“当前推荐下一步”，重试入口可见性不足。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 复盘看板导出失败 | `apps/web/public/app/createApp.js` | 失败提示后聚焦当前推荐下一步 |
| 复盘套件导出失败 | `apps/web/public/app/createApp.js` | 失败提示后聚焦当前推荐下一步 |
| 人工复盘待补任务导出失败 | `apps/web/public/app/createApp.js` | 失败状态回写后聚焦当前推荐下一步 |
| 人工复盘回流预览导出失败 | `apps/web/public/app/createApp.js` | 失败状态回写后聚焦当前推荐下一步 |
| 写回草稿导出失败 | `apps/web/public/app/createApp.js` | 失败状态回写后聚焦当前推荐下一步 |
| 安全写回预览导出失败 | `apps/web/public/app/createApp.js` | 失败状态回写后聚焦当前推荐下一步 |

## 5. 边界

- 未改变任何导出 API。
- 未改变 Obsidian 写入路径。
- 未新增自动重试。
- 未清空复盘面板内容。
- 未改变正式写回成功或失败的既有分支。

## 6. 验收项

- 复盘看板和套件导出失败后，页面保留复盘内容并回到当前推荐下一步。
- 人工复盘待补任务、回流预览、写回草稿、安全写回预览导出失败后，页面保留复盘内容并回到当前推荐下一步。
- 当前推荐下一步卡不存在时，沿用 `focusDashboardNextStep` 的回退聚焦逻辑。
