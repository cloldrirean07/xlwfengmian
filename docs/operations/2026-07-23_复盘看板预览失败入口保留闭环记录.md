# 复盘看板预览失败入口保留闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 5.7：复盘材料生成成功后，页面展示导出状态和下一步建议。
- PRD 5.8：案例读取或复盘材料生成失败后，页面保留入口。
- 既有闭环：`docs/operations/2026-07-22_案例复盘看板入口生成预览闭环记录.md`

## 3. 当前缺口

批次复盘看板预览生成失败时，页面只展示失败提示并返回 `false`，但没有把用户带回复盘看板下一步区域。相比导出失败、复盘套件失败等路径，预览失败缺少一致的恢复定位。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 预览失败提示 | `apps/web/public/app/createApp.js` | 保留接口错误信息或“批次复盘看板生成失败。” |
| 可恢复入口 | `apps/web/public/app/createApp.js` | 预览失败后聚焦复盘看板下一步区域 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加预览失败后保持重试入口可见的断言 |

## 5. 边界

- 未改变批次复盘看板预览 API
- 未改变复盘看板渲染结构
- 未新增自动重试能力
- 未改变导出或正式写回流程

## 6. 验收项

- 批次复盘看板预览失败时展示失败提示
- 批次复盘看板预览失败后回到下一步区域
- 预览失败仍返回 `false`，不误判为成功
