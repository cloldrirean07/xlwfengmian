# 安全预览确认短语复制辅助记录

- 时间：2026-07-28 19:28
- 执行模式：PI Engine 维护模式
- 本轮目标：降低安全预览确认块受控写入入口的操作摩擦，避免人工输入固定确认短语时出错。

## 1. 背景

- 页面已接入安全预览确认块受控写入入口。
- 受控写入必须输入固定确认短语 `确认写入安全预览确认块`。
- 手动输入固定短语容易因空格、漏字或错字导致拦截。

## 2. 修正

- 更新 `public/app/renderers.js`
  - 在受控写入入口中新增“复制短语”按钮。
  - 复制按钮仅在写入预检通过后开放。
- 更新 `public/app/createApp.js`
  - 增加确认短语复制分支。
  - 复制成功后提示“确认短语已复制，可用于写入确认块。”
  - 复制失败时提示手动输入确认短语。
- 更新 `public/styles.css`
  - 将受控写入入口操作区调整为输入框、复制按钮、写入按钮三列布局。
- 更新 `tests/coverAssistantService.test.js`
  - 增加复制按钮、复制动作、反馈文案和渲染入口断言。

## 3. 安全边界

- 复制短语不会触发写入。
- 本轮未自动执行安全预览确认块写入。
- 本轮未写入 Obsidian。
- 本轮未执行正式写回。

## 4. 下一步

- 在页面复制确认短语。
- 将短语粘贴到受控写入入口。
- 点击“写入确认块”，完成安全预览确认块写入。
- 写入后重新检查正式写回门禁。
