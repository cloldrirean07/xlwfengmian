# 安全预览确认写入后门禁复查入口记录

- 时间：2026-07-28 20:01
- 执行模式：PI Engine 维护模式
- 本轮目标：在安全预览确认块写入后复查提示中补充可执行的门禁复查入口。

## 1. 背景

- 受控写入入口已显示写入后的目标状态 `ready-to-formal-write`。
- 页面中已有正式写回门禁复查动作 `check-manual-review-formal-write-readiness`。
- 当前应把复查动作放到确认块写入卡片里，减少写入后回找入口的成本。

## 2. 修正

- 更新 `public/app/renderers.js`
  - 在“写入后复查”区域新增“复查写回门禁”按钮。
  - 复用既有动作 `check-manual-review-formal-write-readiness`。
  - 按钮仅在确认块写入读回通过后开放。
- 更新 `public/styles.css`
  - 调整写入后复查区布局，让说明与按钮并列展示。
- 更新 `tests/coverAssistantService.test.js`
  - 增加复查按钮文案和复用动作断言。

## 3. 安全边界

- 本轮只新增门禁复查入口。
- 本轮未自动执行安全预览确认块写入。
- 本轮未写入 Obsidian。
- 本轮未执行正式写回。

## 4. 下一步

- 执行安全预览确认块写入。
- 写入读回通过后，点击“复查写回门禁”。
- 门禁进入 `ready-to-formal-write` 后，再单独决定是否执行正式写回。
