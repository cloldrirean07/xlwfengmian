# 工作区路径选择闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 3.5：工作区路径为必填，默认值依据首轮配图策略推荐，仅支持枚举值。
- PRD 3.6：工作区路径必须基于当前选中方向展开；切换路径时保留首轮方向上下文，并刷新路径内输入提示。
- Requirement Spec：工作区路径包含“优化现有素材、补内容贴合图、做创意概念图”三个路径。

## 3. 本轮实现映射

| Spec / PRD 条目 | 实现位置 | 实现结果 |
| --- | --- | --- |
| 三条工作区路径枚举 | `src/domain/workspace/buildActionWorkspace.js` | 增加合法路径集合，并支持显式 `workspaceId` 覆盖默认推荐路径。 |
| 每张方向卡可切换三条路径 | `src/application/createAnalysisSession.js` | 每张方向卡新增 `actionWorkspaces`，一次带出三条路径配置。 |
| 生成建议按当前路径执行 | `src/application/createActionWorkspaceSession.js` | 接收前端提交的 `workspaceId`，非法枚举直接拒绝。 |
| 路径选择 UI | `public/index.html`、`public/app/renderers.js`、`public/styles.css` | 新增路径选择区，当前路径高亮，移动端单列展示。 |
| 切换路径刷新路径内输入 | `public/app/createApp.js` | 切换路径后重渲染表单，并清空旧建议与采纳状态。 |
| 提交当前路径 | `public/app/createApp.js` | 工作区建议提交时带上当前 `workspaceId`。 |

## 4. 边界

- 未新增第四条工作区路径。
- 未改变方向卡生成逻辑。
- 未改变案例复盘、导出和规则引擎。
- 未引入新依赖。

## 5. 验收项

- 每张方向卡应包含三条工作区路径。
- 工作区路径选择区应展示三条枚举，并高亮当前路径。
- 用户切换路径后，路径内输入项应刷新。
- 用户切换路径后，旧工作区建议和采纳状态应失效。
- 工作区建议生成应按当前选择路径执行。
- 非法路径枚举应被拒绝。
