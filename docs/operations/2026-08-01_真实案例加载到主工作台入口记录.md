# 真实案例加载到主工作台入口记录

> 记录时间：2026-08-01 16:06 CST

## 本轮目标

补齐真实案例从维护区进入主工作台的入口，让 real-002 / real-003 等真实案例可以直接生成首轮方向卡，并承接标题选择与正式写回链路。

## 实现范围

- 在真实案例卡片操作区新增“加载到主工作台”按钮。
- 新增 `loadCaseIntoMainWorkbench(caseId)` 入口函数，复用既有 `/api/case-run` 链路。
- 加载后自动完成：
  - 回填输入表单字段；
  - 更新首轮分析结果；
  - 清空旧标题选择、旧标题写回结果、旧二轮结果、旧工作区结果；
  - 展开主工作台首轮方向卡；
  - 切回创作主路径视图。
- 补充测试，锁定真实案例卡片按钮、主工作台加载函数和状态清理行为。

## 受控边界

- 本轮不执行真实案例标题正式写回，只补入口。
- 本轮不改真实案例数据文件。
- 本轮不改标题风格库规则。

## 下一步建议

1. 从真实案例卡片点击“加载到主工作台”。
2. 在首轮方向卡里选择一个标题候选并生成写回预览。
3. 输入 `确认写入优选标题`，执行真实案例标题写回。
4. 对 real-002 / real-003 分别复跑，观察标题库候选是否需要继续沉淀规则。
