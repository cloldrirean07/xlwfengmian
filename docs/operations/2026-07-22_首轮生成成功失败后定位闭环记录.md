# 首轮生成成功失败后定位闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/requirements/AI封面创意助手_正式RequirementSpec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_PRD_v0.1.md`

## 2. 对齐条目

- PRD 1.7：生成成功后展示首轮方向结果，并保留本次输入用于后续工作区和二轮修订。
- PRD 1.8：生成失败后保留输入内容和素材预览，并允许用户调整后重试。
- PRD 2.7：用户选中方向后，保留本次首轮结果用于后续建议生成、二轮反馈和案例记录。

## 3. 当前缺口

首轮生成成功后会展示结果，但不稳定回到方向卡区。首轮生成失败后会提示失败，但不稳定回到输入准备表单。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 首轮生成成功定位 | `apps/web/public/app/createApp.js` | 成功后聚焦方向卡区 |
| 首轮生成失败定位 | `apps/web/public/app/createApp.js` | 失败后回到输入准备表单 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加成功/失败后定位断言 |

## 5. 边界

- 未改变输入字段规则
- 未改变首轮方向生成 API
- 未清空输入或素材预览
- 未改变方向卡数据结构
- 未自动选择方向

## 6. 验收项

- 首轮生成成功后，页面展示方向卡区
- 首轮生成失败后，页面回到输入准备表单，保留用户输入与素材预览
