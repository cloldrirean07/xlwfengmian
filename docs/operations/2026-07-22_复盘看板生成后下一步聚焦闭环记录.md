# 复盘看板生成后下一步聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 5.7：复盘材料生成成功后，页面展示导出状态和下一步建议。
- PRD 5.4：生成复盘材料后，用户继续判断是否需要写回或沉淀任务。

## 3. 当前缺口

批次复盘看板结果中已有“当前推荐下一步”卡片，但从案例复盘承接区直接生成看板后，视线仍可能停留在入口或看板标题，用户需要自行寻找结果里的下一步。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 看板生成成功后聚焦下一步 | `public/app/createApp.js` | 在预览成功后调用 `focusDashboardNextStep` |
| 下一步卡定位 | `public/app/renderers.js` | 复用既有 `data-review-next-step-card` |
| 回归测试 | `tests/coverAssistantService.test.js` | 增加成功后聚焦调用断言 |

## 5. 边界

- 未新增复盘看板字段。
- 未改变复盘看板 API。
- 未自动执行导出。
- 未自动执行正式写回。
- 未改变跟进行动卡的现有渲染结构。

## 6. 验收项

- 批次复盘看板预览生成成功后，页面自动滚动到“当前推荐下一步”卡。
- 如果当前没有可定位的下一步卡，原有结果展示保持不变。
- 原看板区按钮与案例复盘承接入口都复用同一生成后聚焦行为。
