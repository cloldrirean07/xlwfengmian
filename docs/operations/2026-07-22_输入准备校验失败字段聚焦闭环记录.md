# 输入准备校验失败字段聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 1.5：必填字段为空时，在字段附近提示对应补充信息，不发起生成，已填内容保留。
- PRD 1.8：生成失败时保留输入内容，用户可再次点击生成。

## 3. 当前缺口

输入准备校验失败时，页面已有字段提示，也不会清空已填内容。但用户提交后不会稳定回到具体失败字段，尤其在页面滚动后需要手动寻找。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 字段校验失败定位 | `apps/web/public/app/createApp.js` | 根据 `validation.fieldName` 聚焦对应输入控件 |
| 回退定位 | `apps/web/public/app/createApp.js` | 找不到字段时回到输入表单 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加首轮字段校验失败后聚焦无效字段的静态断言 |

## 5. 边界

- 未改变输入准备字段规则。
- 未改变表单字段名称。
- 未改变首轮生成接口。
- 未清空已填写内容。
- 未改变素材上传和清除逻辑。

## 6. 验收项

- 内容主题、内容目标、平台或素材类型校验失败时，页面提示原因并聚焦对应字段。
- 已填写字段保持在表单中，用户可直接修改后重新生成。
- 找不到对应字段时，页面回到输入准备表单。
