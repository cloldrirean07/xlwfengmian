# 工作区路径输入长度限制闭环实现记录

## 基本信息

- 日期：2026-07-21
- 模式：PI Engine 维护模式
- 需求依据：[AI封面创意助手_MVP重做_主路径与工作台重做.md](/Users/xlw/Documents/codex1/AI封面创意助手项目/ai-cover-creative-assistant/docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md)
- 本轮目标：补齐工作区深化路径内输入的输入层长度限制，避免用户在页面上输入超过 PRD 约束的单项信息。

## Requirement Spec 映射

| Spec 条目 | 实现映射 |
| --- | --- |
| 3.5 路径内输入单项最多 200 个字符 | 动态渲染的工作区 `input` 与 `textarea` 均增加 `maxlength="200"` |
| 3.5 超长时禁止继续输入或截断粘贴 | 浏览器输入层直接限制继续输入，并与已有提交前校验共同兜底 |
| 3.8 建议生成失败后路径内输入保留 | 本轮只增加输入控件属性，不改动失败处理和表单状态保留逻辑 |

## 验收口径

- 工作区文本输入渲染后包含 `maxlength="200"`。
- 工作区多行输入渲染后包含 `maxlength="200"`。
- 已有提交前校验仍保留“路径信息最多输入 200 个字符”兜底。
- 本轮不改变工作区建议生成、采纳反馈和二轮承接逻辑。

## 风险与边界

- 本轮只处理动态工作区输入层限制。
- 本轮不新增字段计数器。
- 本轮不改动工作区路径推荐逻辑。
