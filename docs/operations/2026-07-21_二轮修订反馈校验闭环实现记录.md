# 二轮修订反馈校验闭环实现记录

## 基本信息

- 日期：2026-07-21
- 阶段：PI Engine 维护模式 / 主路径字段校验补齐
- 对应 PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md` 的 `4.二轮修订`
- 实现范围：`apps/web`

## 需求映射

| PRD 要求 | 当前实现 |
| --- | --- |
| 修订反馈必填 | `validateRefinePayloadFields` 对去除首尾空格后的 `feedback` 判空 |
| 空值提示“请输入修改意见” | 校验失败时写入字段 `setCustomValidity` 并同步状态栏 |
| 占位文案“例如：更高级一点，但不要太平” | 二轮修订反馈 textarea 已更新为指定占位文案 |
| 最多 200 个字符 | HTML `maxlength="200"` 与 JS 校验双层约束 |
| 超长提示“修改意见最多输入 200 个字符” | JS 校验返回统一产品提示，不发起二轮修订 |
| 未选择方向提示“请先选择一个封面方向” | 二轮提交前若缺少当前方向，直接提示并停止请求 |

## 修改边界

- 未改动首轮方向生成、二轮生成服务、规则目录和案例复盘数据结构。
- 未新增后端接口。
