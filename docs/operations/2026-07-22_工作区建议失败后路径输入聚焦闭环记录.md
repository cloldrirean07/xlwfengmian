# 工作区建议失败后路径输入聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 3.5：路径内输入生成建议前至少填写 1 项，未填写时提示“请补充至少一项路径信息”。
- PRD 3.8：建议生成失败展示“建议生成失败，请重试”，路径内输入保留。

## 3. 当前缺口

工作区建议失败时，页面已有提示，路径内输入也没有被清空。但失败后页面不会稳定回到工作区输入区，用户需要自己找回可修改和重试的位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 路径输入校验失败 | `apps/web/public/app/createApp.js` | 提示后聚焦工作区输入区 |
| 工作区建议请求失败 | `apps/web/public/app/createApp.js` | 提示后聚焦工作区输入区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加失败后聚焦保留输入的静态断言 |

## 5. 边界

- 未改变工作区路径枚举。
- 未改变路径内输入字段规则。
- 未清空用户已填写路径输入。
- 未改变建议生成接口。
- 未改变采纳或暂不采纳状态逻辑。

## 6. 验收项

- 路径内输入为空时，页面提示“请补充至少一项路径信息”，并聚焦工作区输入区。
- 工作区建议生成失败时，页面提示“建议生成失败，请重试”，并聚焦工作区输入区。
- 用户已填写的路径内输入保持在表单内，便于修改后重试。
