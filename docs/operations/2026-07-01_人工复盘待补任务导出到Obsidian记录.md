# 2026-07-01_人工复盘待补任务导出到Obsidian记录

## 1. 本轮目标

- 把复盘看板里的人工待补任务，推进成可导出的填写草稿。

## 2. 本轮完成内容

已完成：

- 新增人工待补任务 Markdown 生成
- 新增 Obsidian 草稿封装
- 新增 preview/export 应用层
- 新增服务端接口
- 新增前端导出按钮与动作接线
- 补充对应测试
- 补一份架构说明文档

## 3. 这轮解决的问题

之前系统已经能给出待补任务卡，但它仍然停留在页面里。

这轮之后，用户可以直接把这张任务卡导出到 Obsidian，作为实际填写材料。

## 4. 对后续推进的影响

这会让“补人工复盘 -> 再判断 UI 时机”这条链更完整：

- 不用再手动抄字段
- 更容易把真实判断留痕
- 更容易在补完后回头重跑 UI readiness
