# 批量真实案例预览写入承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：真实案例复盘失败后保留当前补充内容。
- Requirement Spec：生成成功后展示导出状态，失败后保留当前补充内容。
- Requirement Spec：案例复盘与规则沉淀需要将真实案例、批次试跑和人工复盘沉淀为后续规则优化依据。

## 3. 当前缺口

批量真实案例骨架预览和确认写入已有成功/失败提示，但成功后不稳定进入对应结果区，失败后也不稳定回到可调整输入或可重试预览位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 批量预览成功 | `apps/web/public/app/createApp.js` | 定位到批量预览结果区 |
| 批量预览失败 | `apps/web/public/app/createApp.js` | 保留批量 JSON 并回到批量输入区 |
| 批量写入缺少预览 | `apps/web/public/app/createApp.js` | 提示先预览并定位批量预览区 |
| 批量写入成功 | `apps/web/public/app/createApp.js` | 定位到批量写入结果区 |
| 批量写入失败 | `apps/web/public/app/createApp.js` | 保留预览结果并定位批量预览区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加批量预览与写入承接断言 |

## 5. 边界

- 未改变批量真实案例 JSON 结构
- 未改变批量预览或写入 API
- 未改变案例库刷新逻辑
- 未改变批量回填工作单、批次试跑记录和复盘看板链路
- 未新增业务流程

## 6. 验收项

- 批量预览成功后，页面进入批量预览结果区
- 批量预览失败后，保留批量输入并回到批量输入区
- 批量写入成功后，页面进入写入结果区
- 批量写入失败后，保留预览结果并回到可重试区域
