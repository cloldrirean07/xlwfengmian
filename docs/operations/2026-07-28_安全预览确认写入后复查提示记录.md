- 受控写入入口已支持短语填入和短语匹配解锁。

- 正式写回仍必须独立确认，不能和确认块写入合并成同一步。

  - 明确目标状态为 `ready-to-formal-write`。
  - 提醒达成后仍需单独执行正式写回。
- 更新 `public/styles.css`
  - 增加复查提示区样式。
- 更新 `tests/coverAssistantService.test.js`
  - 增加写入后复查、目标状态和正式写回独立确认提示断言。

## 3. 安全边界

- 本轮只补充复查提示。
- 本轮未自动执行安全预览确认块写入。
- 本轮未写入 Obsidian。
- 本轮未执行正式写回。

## 4. 下一步

- 填入确认短语并执行“写入确认块”。
- 写入成功后检查正式写回门禁。
- 只有门禁进入 `ready-to-formal-write` 后，才进入正式写回确认。
