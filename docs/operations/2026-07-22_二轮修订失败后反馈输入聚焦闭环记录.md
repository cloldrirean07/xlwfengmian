# 二轮修订失败后反馈输入聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 4.5：修订反馈为空时，字段附近提示“请输入修改意见”。
- PRD 4.8：修订失败展示“修订失败，请重试”，反馈内容保留。

## 3. 当前缺口

二轮修订失败时，页面已有失败提示，也没有清空反馈内容。但失败后页面不会稳定回到反馈输入区，用户需要自己重新定位可修改位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 字段校验失败 | `apps/web/public/app/createApp.js` | 提示后聚焦二轮反馈输入 |
| 结果完整性失败 | `apps/web/public/app/createApp.js` | 提示后聚焦二轮反馈输入 |
| 修订请求失败 | `apps/web/public/app/createApp.js` | 提示后聚焦二轮反馈输入 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加失败后聚焦反馈输入的静态断言 |

## 5. 边界

- 未改变二轮修订接口。
- 未改变反馈字段校验规则。
- 未清空已填写反馈。
- 未改变二轮结果渲染结构。
- 未改变工作区建议接入规则。

## 6. 验收项

- 修改意见为空时，页面提示“请输入修改意见”并聚焦反馈输入。
- 修订结果不完整时，页面提示“修订失败，请重试”并聚焦反馈输入。
- 修订请求失败时，页面提示“修订失败，请重试”并聚焦反馈输入。
