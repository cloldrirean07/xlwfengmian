# 2026-07-01_复盘看板人工待补任务卡接入记录

## 1. 本轮目标

- 把“当前最该补的人工复盘内容”收成更直接的任务卡。

## 2. 本轮完成内容

已完成：

- 新增 `manualReviewTaskCard`
- 接入复盘看板报告结构
- 接入 Markdown 输出
- 接入前端展示
- 补充对应测试
- 补一份架构说明文档

## 3. 这轮解决的问题

之前系统已经能告诉你：

- 哪一批最该补

但还不能直接告诉你：

- 这一批到底要补哪些关键字段
- 每个字段该怎么写

这轮之后，复盘看板开始更像一个待办工作台，而不是只有判断结果。

## 4. 对后续推进的影响

这会让下一步实际补人工复盘更顺：

- 不用再来回切换到别的文档查字段含义
- 补完后也更容易直接进入下一轮 UI 时机判断

## 6. 下一步建议

下一步最适合继续做的是：

1. 基于一个真实待补批次，实际用这张任务卡补一次人工复盘
2. 再重跑 UI readiness 和复盘看板
3. 观察这条链路是否已经足够支撑首页系统 UI 讨论
