# 方向选择异常后结果区聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 2.5：进入工作区或二轮修订前必须先选择方向，未选择时提示“请先选择一个封面方向”。
- PRD 2.8：方向不存在时，提示“当前方向已失效，请重新选择”。
- PRD 3.8：未选择方向时，不展示路径输入，并提示“请先选择一个封面方向”。

## 3. 当前缺口

方向选择异常时，页面已有提示，但没有稳定把用户带回方向卡列表。用户需要自己寻找可重新选择的方向卡，主路径承接不够直接。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 首轮结果不完整 | `apps/web/public/app/createApp.js` | 提示后聚焦方向卡结果区 |
| 二轮入口方向缺失或失效 | `apps/web/public/app/createApp.js` | 提示后聚焦方向卡结果区 |
| 工作区入口方向缺失或失效 | `apps/web/public/app/createApp.js` | 提示后聚焦方向卡结果区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加方向选择异常后回到结果区的静态断言 |

## 5. 边界

- 未改变首轮方向卡生成逻辑。
- 未改变方向选择状态结构。
- 未改变工作区路径枚举。
- 未改变二轮修订接口。
- 未新增任何业务状态。

## 6. 验收项

- 首轮结果不完整时，页面提示“方向结果不完整，请重新生成”，并回到方向卡结果区。
- 二轮入口没有有效方向时，页面提示原因，并回到方向卡结果区。
- 工作区入口没有有效方向时，页面提示原因，并回到方向卡结果区。
