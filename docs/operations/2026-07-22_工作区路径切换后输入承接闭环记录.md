# 工作区路径切换后输入承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：工作区路径选择要求用户选择路径后，页面展示该路径对应的输入项和建议生成动作。
- Requirement Spec：路径切换时保留首轮方向信息，路径内输入按当前路径重置或更新。
- PRD 信息架构 3：工作区分为优化现有素材、补内容贴合图、做创意概念图，建议生成后支持采纳或暂不采纳。

## 3. 当前缺口

工作区路径切换后已更新路径状态和输入项，但页面不稳定进入更新后的路径输入区，用户需要自行寻找下一步填写位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 路径切换承接 | `apps/web/public/app/createApp.js` | 切换路径后聚焦工作区输入区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加路径切换后定位断言 |

## 5. 边界

- 未改变工作区路径枚举
- 未改变路径内字段规则
- 未改变建议生成接口
- 未改变采纳或暂不采纳状态
- 未自动生成建议

## 6. 验收项

- 用户切换工作区路径后，当前路径高亮并展示对应输入项
- 页面自动回到工作区输入区，方便补充信息后重新生成建议
