# 真实案例库读取失败后列表承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：真实案例复盘需要包含案例状态、缺失字段、优先补充项、复盘材料生成动作。
- Requirement Spec：失败后页面提示失败原因，并保留可重试入口。
- Requirement Spec：用户查看案例缺口，补充关键字段，生成复盘或回填材料。

## 3. 当前缺口

真实案例库读取失败时，页面只更新状态文案。若用户当前停留在其他区域，失败后不会自动回到案例列表，导致刷新、筛选或点击案例动作失败后缺少明确的可继续处理位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 案例列表定位 | `apps/web/public/app/createApp.js` | 新增真实案例库结果区聚焦函数 |
| 读取失败承接 | `apps/web/public/app/createApp.js` | 进入案例、刷新、筛选和列表动作失败后回到案例列表 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加读取失败后回到案例列表断言 |

## 5. 边界

- 未改变案例读取 API
- 未改变真实案例筛选规则
- 未改变真实案例补充、导出和平台同步逻辑
- 未新增业务按钮或状态流转

## 6. 验收项

- 真实案例库读取失败后显示失败提示
- 页面回到案例列表区域
- 用户仍能继续刷新、筛选或选择其他案例
