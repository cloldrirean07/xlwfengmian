# 写回失败后状态面板聚焦闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 5.8：写回失败展示“写回失败，请检查后重试”，目标记录保持原状态。
- PRD 5.6：导出或写回失败时，原案例状态保持不变。

## 3. 当前缺口

正式写回执行失败时已有失败提示和失败状态渲染，但失败后视线未回到正式写回状态区。用户需要重新定位失败上下文。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 正式写回失败反馈 | `apps/web/public/app/createApp.js` | 失败后提示并聚焦正式写回状态区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加失败分支断言 |

## 5. 边界

- 未改变正式写回 API。
- 未改变写回恢复逻辑。
- 未自动重试。
- 未修改目标记录。
- 未改变成功分支承接任务聚焦。

## 6. 验收项

- 正式写回执行失败后，页面显示“写回失败，请检查后重试”。
- 正式写回执行失败后，页面聚焦到正式写回状态区。
- 如果状态区尚未渲染，仍回退聚焦到推荐下一步卡。
