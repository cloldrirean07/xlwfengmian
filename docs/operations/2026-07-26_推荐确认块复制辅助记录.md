# 推荐确认块复制辅助记录

## 1. 本轮定位

[事实] 本轮继续按 PI Engine 维护模式推进真实案例数据闭环。

[事实] 上一轮已经把人工确认交接包接入写回态页面。

[事实] 本轮目标是降低人工迁移推荐确认块时的漏行风险。

## 2. 本轮调整

[事实] 人工确认交接包面板新增“复制确认块”按钮。

[事实] 按钮只复制页面中已经展示的推荐确认块。

[事实] 复制成功后，页面状态条显示“确认块已复制，可写入安全预览记录。”。

[事实] 复制失败时，页面状态条提示从交接包面板选取确认块。

## 3. 边界

[事实] 本轮不写入 Obsidian。

[事实] 本轮不执行正式写回。

[事实] 本轮不改变正式写回门禁逻辑。

## 4. 下一步

[需确认] 若继续推进正式写回链路，需要确认采用推荐确认块，并将其写入 Obsidian 安全预览记录。
