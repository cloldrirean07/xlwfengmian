# 2026-07-21 输入准备字段校验闭环实现记录

## 1. 执行模式

- 执行方式：PI Engine 维护模式
- 依据文档：
  - `docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`
  - `docs/architecture/AI封面创意助手产品线重做架构计划_v0.1.md`
- 本轮目标：
  - 按 PRD 输入准备字段规则补齐首轮分析前校验
  - 在校验失败时保留输入，不发起首轮生成
  - 复用现有表单、状态栏和首轮分析链路

## 2. 实现映射

| Spec 条目 | 实现位置 | 实现说明 |
| --- | --- | --- |
| 内容主题必填、最多 80 个字符 | `apps/web/public/index.html`、`apps/web/public/app/createApp.js` | 增加 `maxlength="80"`，提交前校验空值和长度。 |
| 内容目标必填、最多 120 个字符 | `apps/web/public/index.html`、`apps/web/public/app/createApp.js` | 增加 `maxlength="120"`，提交前校验空值和长度。 |
| 目标平台必选且只能从枚举中选择 | `apps/web/public/app/createApp.js` | 校验平台必须为抖音、小红书或 Instagram。 |
| 素材类型必选且只能从枚举中选择 | `apps/web/public/app/createApp.js` | 校验素材类型必须为截图、人像、场景图、商品图或无图只有想法。 |
| 素材描述最多 300 个字符 | `apps/web/public/index.html`、`apps/web/public/app/createApp.js` | 增加 `maxlength="300"`，提交前校验长度。 |
| 封面倾向最多 120 个字符 | `apps/web/public/index.html`、`apps/web/public/app/createApp.js` | 增加 `maxlength="120"`，提交前校验长度。 |
| 补充说明最多 300 个字符 | `apps/web/public/index.html`、`apps/web/public/app/createApp.js` | 增加 `maxlength="300"`，提交前校验长度。 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 新增输入准备字段校验测试。 |

## 4. 文案自检

本轮新增校验文案：

- `请输入内容主题`
- `请输入内容目标`
- `请选择目标平台`
- `请选择素材类型`
- `目标平台不可用，请重新选择`
- `素材类型不可用，请重新选择`
- `内容主题最多输入 80 个字符`
- `内容目标最多输入 120 个字符`
- `素材描述最多输入 300 个字符`
- `封面倾向最多输入 120 个字符`
- `补充说明最多输入 300 个字符`

以上文案均为产品级操作反馈，没有使用对话式表达。

```bash
node --check public/app/createApp.js
npm test
```

- 首页资源可正常返回
