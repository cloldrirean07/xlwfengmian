# 2026-06-26 真实案例回填导出双模式策略记录

## 本次动作

- 单案例导出增加 `overwrite` / `copy` 两种模式
- 前端增加“覆盖导出”与“新建副本”两个动作
- 导出结果增加模式说明
- 补充副本模式测试与定向验证

## 本次目的

让真实案例回填导出不再只有一种固定写入行为，而是支持明确的导出策略选择。

## 本次实现结果

当前真实案例卡片可直接触发：

- 覆盖当前 Obsidian 草稿
- 新建一份副本草稿

副本模式会生成带 `__副本_<exportId>` 的文件名，不会影响主路径文件。

## 验证

- `npm test`
- `node --input-type=module -e "...exportRealCaseFillSheetToObsidian({ caseId: 'real-001', exportMode: 'overwrite' })..."`
- `node --input-type=module -e "...exportRealCaseFillSheetToObsidian({ caseId: 'real-001', exportMode: 'copy' })..."`
- `node --check public/app/createApp.js`
- `node --check public/app/renderers.js`

## 当前影响

这次改动让真实案例回填导出链从“只有一个写法”升级成“有策略可选的写法”。

后续如果继续推进，更自然的方向是：

- 副本命名策略可配置
- 导出前后差异提示
- 再在合适时机讨论是否需要更明显的 UI 分步引导
