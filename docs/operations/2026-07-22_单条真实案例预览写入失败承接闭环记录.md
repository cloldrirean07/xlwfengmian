# 单条真实案例预览写入失败承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：真实案例复盘失败后保留当前补充内容。
- Requirement Spec：生成成功后展示导出状态，失败后保留当前补充内容。
- PRD 信息架构 5：案例复盘与规则沉淀需保留真实案例、平台案例、批次复盘和写回确认能力。

## 3. 当前缺口

单条真实案例骨架预览和确认写入缺少异常承接。预览或写入失败时，页面可能无法给出稳定失败提示，也不会回到可重试区域。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 单条案例预览失败 | `apps/web/public/app/createApp.js` | 提示预览失败并回到录入表单 |
| 单条案例预览成功 | `apps/web/public/app/createApp.js` | 定位到骨架预览结果 |
| 单条案例写入缺少预览 | `apps/web/public/app/createApp.js` | 提示先预览并定位预览区域 |
| 单条案例写入失败 | `apps/web/public/app/createApp.js` | 提示写入失败并定位预览区域 |
| 单条案例写入成功 | `apps/web/public/app/createApp.js` | 定位到写入结果区 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加预览和写入失败承接断言 |

## 5. 边界

- 未改变真实案例字段结构
- 未改变真实案例写入 API
- 未改变案例库刷新逻辑
- 未新增案例复盘业务流程
- 未修改批量案例链路

## 6. 验收项

- 单条案例预览失败后，保留表单输入并提示可检查后重试
- 单条案例写入失败后，保留预览结果并提示可检查后重试
- 单条案例成功预览或写入后，页面进入对应结果区
