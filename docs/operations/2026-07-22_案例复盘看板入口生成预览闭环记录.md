# 案例复盘看板入口生成预览闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md`

## 2. 对齐条目

- PRD 5.4：进入案例复盘后，用户可生成复盘材料。
- PRD 5.7：复盘材料生成成功后，页面展示导出状态和下一步建议。
- PRD 5.8：生成失败时，页面保留入口并提示失败原因。

## 3. 当前缺口

案例复盘承接区已有“生成复盘看板”入口，但此前该入口只展开验证复盘组并滚动到看板位置；真正的看板预览仍需再次点击看板区按钮。主路径到复盘材料生成之间还多一层手动动作。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 复盘看板预览流程复用 | `public/app/createApp.js` | 新增 `generateBatchReviewDashboardPreview` |
| 承接入口直接生成看板 | `public/app/createApp.js` | 新增 `enterBatchReviewDashboardWorkspace` |
| 原按钮行为保持一致 | `public/app/createApp.js` | 原按钮复用同一预览流程 |
| 回归测试 | `tests/coverAssistantService.test.js` | 增加入口触发预览流程断言 |

## 5. 边界

- 未自动导出复盘看板到 Obsidian。
- 未自动执行复盘套件导出。
- 未自动执行正式写回。
- 未改变批次复盘看板 API。
- 未改变复盘看板渲染结构。

## 6. 验收项

- 点击案例复盘承接区的“生成复盘看板”后，验证复盘组展开。
- 页面直接生成批次复盘看板预览。
- 原看板区“生成复盘看板”按钮仍可生成相同预览。
- 生成失败时展示“批次复盘看板生成失败。”或接口返回的错误信息。
