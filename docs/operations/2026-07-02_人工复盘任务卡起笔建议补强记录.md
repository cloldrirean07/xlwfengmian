# 2026-07-02_人工复盘任务卡起笔建议补强记录

## 1. 本轮目标

- 降低人工复盘任务卡的填写门槛。
- 解决“只有字段问题和提示，但用户面对空白不知道怎么起笔”的问题。

## 2. 本轮改动

本轮没有改动整体流程顺序，而是在现有任务卡链路里新增了一层：

- 起笔建议
- 可直接改写起笔句

接入位置：

- `apps/web/src/domain/review/buildBatchReviewManualTaskCard.js`
- `apps/web/src/domain/review/buildBatchReviewManualTaskCardMarkdown.js`
- `apps/web/public/app/renderers.js`

## 3. 当前具体做法

系统现在会根据当前批次的：

- 最强摩擦点
- 最该先补的信息
- 当前是否已有人工结论

为 4 个关键字段自动生成“起笔建议”：

- 最卡环节
- 问题类型判断
- 最该前置模块
- UI 时机判断

它不是替用户做最终判断，而是把空白输入改成“可直接改写的起笔句”。

## 5. 这轮对产品推进的意义

这一步的价值不在于让系统替代人工复盘，而在于：

1. 降低第一次填写的心理阻力
2. 让“补 4 个关键字段”更像编辑和修正，而不是从零写作
3. 让当前主阻塞从“不会起笔”进一步收缩成“是否愿意给判断”

## 6. 当前结论

可以把这次补强压缩成一句话：

**人工复盘任务卡现在不再只是空白表单，而是变成了带起笔建议的半成品草稿。**
