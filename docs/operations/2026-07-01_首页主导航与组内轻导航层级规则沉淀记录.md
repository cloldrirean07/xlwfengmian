# 2026-07-01_首页主导航与组内轻导航层级规则沉淀记录

## 1. 本轮目标

- 把首页主导航与组内轻导航的层级关系正式讲清楚。
- 避免后续系统 UI 讨论时把两层导航混在一起。

## 2. 本轮完成内容

已完成：

- 定义首页主导航与组内轻导航的职责区别
- 定义两层导航的文案规则
- 定义两层导航的视觉层级关系
- 补一层轻量样式强化，让主导航和组内轻导航差异更明确

## 3. 产出文件

- `docs/architecture/首页主导航与组内轻导航层级规则_v0.1.md`

## 4. 本轮判断

这轮说明项目已经不再只是零散做导航，而是在开始搭首页导航架构。

这很重要，因为只有把：

- 页面级分流
- 工作台级分流

分开，后面再讨论系统 UI 才不会越做越乱。

## 5. 下一步建议

下一步最适合继续做的是：

1. 判断当前首页是否已经达到“可以正式进入系统 UI 讨论”的门槛
2. 如果达到，再整理首页统一 UI 讨论框架
3. 之后再进入更完整的 UI 方案讨论
