# 安全预览确认受控写入壳记录

- 时间：2026-07-28 19:12
- 执行模式：PI Engine 维护模式
- 本轮目标：在采用推荐确认块后，补齐安全预览确认块的受控写入准备层。

## 1. 背景

- 人工决策已采用推荐确认块。
- 安全预览确认写入预检已通过。
- 正式写回仍不能直接执行，需先将确认块写入安全预览记录并重新检查门禁。

## 2. 修正

- 新增 `src/application/applyManualConfirmationSafePreviewWrite.js`
  - 增加固定确认短语 `确认写入安全预览确认块`。
  - 写入前重新执行安全预览确认写入预检。
  - 仅在预检通过、目标路径存在、建议版本路径存在时允许写入。
  - 写入后执行读回校验，失败时恢复写入前内容。
- 更新 `src/server/server.js`
  - 增加受控接口 `/api/batch-review-manual-confirmation-safe-preview-write-apply`。
  - 接口必须收到确认短语才会触发写入。
- 更新 `tests/coverAssistantService.test.js`
  - 增加确认短语缺失拦截测试。
  - 增加临时文件写入与读回测试。
  - 增加预检未通过拦截测试。
  - 增加服务端路由接入断言。

## 3. 安全边界

- 本轮未向接口发送正确确认短语。
- 本轮未写入 Obsidian。
- 本轮未执行正式写回。
- 测试中的写入只发生在系统临时目录。

## 4. 下一步

- 如需继续推进，先人工确认是否允许将推荐确认块写入安全预览记录。
- 安全预览记录完成写入后，再重新检查正式写回门禁。
- 正式写回仍需单独确认后执行。
