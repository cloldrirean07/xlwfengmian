# 单个真实案例失败原因透出闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：真实案例复盘失败后保留当前补充内容。
- Requirement Spec：案例复盘失败后页面提示失败原因，并保留可重试入口。
- Requirement Spec：真实案例复盘需要包含案例状态、缺失字段、优先补充项、复盘材料生成动作。

## 3. 当前缺口

单个真实案例骨架预览和写入失败时，页面只展示固定失败文案。若底层校验或写入函数已经返回具体原因，用户无法直接知道需要修正哪类输入或文件状态。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 预览失败原因 | `apps/web/public/app/createApp.js` | 单个真实案例骨架预览失败时优先展示 `Error.message` |
| 写入失败原因 | `apps/web/public/app/createApp.js` | 单个真实案例写入失败时优先展示 `Error.message` |
| 可重试入口 | `apps/web/public/app/createApp.js` | 预览失败仍回到表单，写入失败仍回到预览结果 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加单个真实案例失败原因透出断言 |

## 5. 边界

- 未改变真实案例 payload 结构
- 未改变真实案例写入 API
- 未改变批量真实案例链路
- 未新增自动修复或自动写入能力

## 6. 验收项

- 单个真实案例预览失败时展示底层失败原因
- 单个真实案例写入失败时展示底层失败原因
- 失败后仍保留可继续修改或重试的位置
