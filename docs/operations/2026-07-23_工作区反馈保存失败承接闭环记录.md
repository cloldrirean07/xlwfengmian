# 工作区反馈保存失败承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：工作区建议生成后支持采纳或暂不采纳。
- Requirement Spec：建议采纳反馈包含采纳、暂不采纳、当前反馈状态、继续调整入口。
- Requirement Spec：暂不采纳状态保留建议内容并强调可重新生成。

## 3. 当前缺口

工作区建议的采纳或暂不采纳保存失败时，页面缺少失败承接。用户会停留在未处理异常状态，无法直接看到保存失败原因，也缺少明确回到路径输入继续处理的位置。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 保存中状态 | `apps/web/public/app/createApp.js` | 保存工作区反馈时禁用采纳和不采纳按钮 |
| 失败原因 | `apps/web/public/app/createApp.js` | 保存失败时优先展示 `Error.message` |
| 可恢复入口 | `apps/web/public/app/createApp.js` | 失败后保留建议内容并回到路径输入区域 |
| 状态字段 | `apps/web/public/app/state.js` | 增加工作区反馈保存中的状态标记 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加保存失败后保持建议可恢复的断言 |

## 5. 边界

- 未改变工作区建议生成逻辑
- 未改变采纳或不采纳的业务含义
- 未改变二轮修订接入工作区建议的条件
- 未新增自动重试或自动修复能力

## 6. 验收项

- 工作区反馈保存中禁用重复提交
- 保存失败时展示失败原因
- 保存失败后仍保留工作区建议和可继续调整入口
