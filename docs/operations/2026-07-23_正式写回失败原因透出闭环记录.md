# 正式写回失败原因透出闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：案例复盘失败后页面提示失败原因，并保留可重试入口。
- Requirement Spec：正式写回前展示确认状态，未确认时不执行正式写回。
- Requirement Spec：批次复盘看板需要包含写回状态和下一步建议。

## 3. 当前缺口

正式写回执行失败时，页面只展示固定失败文案。若底层写回函数已经返回更具体的错误原因，用户无法在页面上直接看到失败原因，只能得到笼统的重试提示。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 失败原因透出 | `apps/web/public/app/createApp.js` | 正式写回执行失败时优先展示 `Error.message` |
| 兜底提示 | `apps/web/public/app/createApp.js` | 非标准错误仍回退到固定失败提示 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加正式写回失败分支保留错误原因的断言 |

## 5. 边界

- 未改变正式写回前置校验
- 未改变正式写回写文件逻辑
- 未改变失败后的状态面板定位
- 未新增自动写回或自动修复能力

## 6. 验收项

- 正式写回失败时展示底层失败原因
- 失败后仍定位到正式写回状态面板
- 非标准错误仍保留通用重试提示
