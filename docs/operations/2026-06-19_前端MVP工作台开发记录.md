# 2026-06-19 前端 MVP 工作台开发记录

## 本次目标

把 `apps/web` 从偏测试台的单页，推进成更接近真实产品演示形态的 MVP 工作台，同时保持前端代码可继续扩展。

## 本次完成

### 1. 页面结构升级

当前页面已经从简单表单 + 结果区，升级为 6 个明确分区：

- Hero
- Workflow Strip
- MVP Workbench
- Decision Frame
- First Round
- Second Round
- Model Layer
- Operations Desk

这样页面开始同时承载：

- 用户输入
- 系统判断逻辑说明
- 首轮结果
- 二轮改单
- Prompt / LLM Draft
- 平台案例复核入口

### 2. 前端脚本模块化

原本 `public/main.js` 承担了全部职责，现在已经拆成：

- `public/main.js`
- `public/app/createApp.js`
- `public/app/api.js`
- `public/app/dom.js`
- `public/app/renderers.js`
- `public/app/state.js`

这一步的意义是让：

- 状态管理
- DOM 引用
- 页面渲染
- API 请求
- 流程控制

开始具备清晰边界。

### 3. 首轮结果表达增强

首轮结果现在不只显示 3 张卡片，还额外展示：

- 主点击机制
- 内容类型
- 输入模式
- 平台
- 当前判断信号
- 匹配到的适配信号
- 候选配图方向
- 候选图优先顺序

这样页面更贴近你要做的“建议 + 结果”的产品路线。

### 4. 二轮改单体验增强

当前二轮已经支持：

- 明确选中某张卡
- 页面内高亮当前选中卡
- 展示当前选中方向摘要
- 输入保留点和调整反馈
- 输出二轮优化后的结果卡

### 5. README 路径清理

`apps/web/README.md` 中旧的 `shige` 路径已经改为当前真实路径 `codex1/ai-cover-creative-assistant`，避免后续命令执行混乱。
