# 批量回填工作单预览导出承接闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：真实案例复盘生成成功后展示导出状态，失败后保留当前补充内容。
- Requirement Spec：案例复盘区包含真实案例入口、批次复盘入口、人工待补任务、导出状态和规则修订提示。
- PRD 信息架构 5：案例复盘与规则沉淀保留真实案例、批次复盘和写回确认能力。

## 3. 当前缺口

批量回填工作单预览、导出和历史读取已有状态提示，但成功后不稳定进入工作单结果区，失败后也不稳定回到可修改输入或可重试结果区。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 工作单预览成功 | `apps/web/public/app/createApp.js` | 定位到工作单结果区 |
| 工作单预览失败 | `apps/web/public/app/createApp.js` | 保留批量输入并回到批量输入区 |
| 工作单导出成功 | `apps/web/public/app/createApp.js` | 定位到工作单结果区 |
| 工作单导出失败 | `apps/web/public/app/createApp.js` | 保留已有结果并定位工作单结果区 |
| 历史读取成功/失败 | `apps/web/public/app/createApp.js` | 定位工作单结果区以继续检查或重试 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加工作单预览、导出和历史读取承接断言 |

## 5. 边界

- 未改变批量案例 JSON 结构
- 未改变工作单预览、导出或历史读取 API
- 未改变 Obsidian 写入底层
- 未改变批次试跑记录和批次复盘看板链路

## 6. 验收项

- 工作单预览成功后，页面进入工作单结果区
- 工作单预览失败后，页面回到批量输入区
- 工作单导出和历史读取后，页面保持在工作单结果区以便继续处理
