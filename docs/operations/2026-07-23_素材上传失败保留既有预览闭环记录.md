# 素材上传失败保留既有预览闭环记录

## 1. 执行依据

- Skill：`ai-pi-engine`
- 模式：维护模式
- Requirement Spec：`docs/prd/AI封面创意助手重做_Requirement_Spec_v0.1.md`
- PRD 信息架构：`docs/prd/AI封面创意助手_MVP重做_PRD_信息架构确认_v0.1.md`

## 2. 对齐条目

- Requirement Spec：素材上传失败时保留其他已填内容。
- Requirement Spec：用户上传本地参考图后，素材预览区展示文件名、尺寸或预览图。
- Requirement Spec：用户可清除素材并重新选择。

## 3. 当前缺口

用户已有本地素材预览后，再选择一个无法预览的文件，页面会清掉原有素材预览。失败提示虽然存在，但旧素材上下文被移除，用户需要重新选择原素材。

## 4. 本轮实现映射

| 条目 | 位置 | 结果 |
| --- | --- | --- |
| 成功替换 | `apps/web/public/app/createApp.js` | 新素材预览构建成功后再释放并替换旧预览 |
| 失败保留 | `apps/web/public/app/createApp.js` | 新素材预览失败时保留既有 `state.assetPreview` |
| 文件选择复位 | `apps/web/public/app/createApp.js` | 失败后清空本次文件选择，便于重新选择 |
| 回归测试 | `apps/web/tests/coverAssistantService.test.js` | 增加上传失败不调用 `clearLocalAsset` 的断言 |

## 5. 边界

- 未改变清除素材按钮逻辑
- 未改变首轮分析 payload 的素材上下文字段
- 未改变图片类型和尺寸读取规则
- 未新增素材上传后端接口

## 6. 验收项

- 已有素材预览时，新素材预览失败不会清掉旧预览
- 新素材预览成功后正常替换旧预览
- 用户仍可通过清除按钮主动移除素材预览
