# 安全预览写入前复查门禁强化记录

- 时间：2026-07-28 17:16
- 执行模式：PI Engine 维护模式
- 本轮目标：在采用推荐确认块后，将人工决策证据纳入正式写回前的安全预览复查门禁。

## 1. 背景

- 人工确认决策记录已从 `pending` 推进为 `adopt-recommended`。
- 正式写回 readiness 原先主要检查安全写回预览读回与人工确认字段。
- 为避免安全预览确认与人工采用决策脱节，本轮补齐人工决策门禁。

## 2. 修正

- 更新 `src/application/runBatchReviewManualFormalWriteReadinessPreview.js`
  - 读取项目内人工确认决策记录。
  - 当决策未采用推荐确认块时返回 `awaiting-manual-decision-adoption`。
  - 当安全预览已确认且人工决策已采用时，才返回 `ready-to-formal-write`。
- 更新 `public/app/createApp.js`
  - 正式写回动作前增加人工决策校验。
  - 未采用推荐确认块时提示先完成采用。
- 更新 `public/app/renderers.js`
  - 写回门禁进度增加“人工决策”步骤。
  - 正式写回状态面板展示人工决策状态。
  - 正式写回按钮只在安全预览确认与人工决策采用同时满足时展示。
- 更新 `tests/coverAssistantService.test.js`
  - 增加后端 readiness 人工决策门禁测试。
  - 增加前端按钮锁定与放行测试。

## 3. 安全边界

- 本轮不写入 Obsidian。
- 本轮不执行正式写回。
- 本轮不改正式写回落盘逻辑。
- 本轮只补齐正式写回前的项目内门禁证据链。
