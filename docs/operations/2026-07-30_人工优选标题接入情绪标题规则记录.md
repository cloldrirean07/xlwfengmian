# 人工优选标题接入情绪标题规则记录

- 记录时间：2026-07-30 15:23
- 项目：AI 封面创意助手
- 本轮目标：把 `real-002 / real-003` 的人工优选标题写入真实案例，并实现第一版“素材关键词 -> 情绪标题”生成规则。

## 1. 问题来源

[事实] 上一轮“真实素材关键词注入标题建议”已经让标题包含具体素材词，但输出仍偏解释型，例如“辣炒鱿鱼、螃蟹、香菜封面里最容易被忽略的反差点”。

[事实] 用户给出两条更像真实封面文案的人工标题：

- `real-002`：辣炒的味蕾
- `real-003`：最后一抹霞光

[推断] 这说明产品需要从“素材词注入”继续走向“素材词到情绪标题的转译”。

## 2. 本轮实现

- 在 `real-002` 写入 `copyReview.preferredTitle = "辣炒的味蕾"`。
- 在 `real-003` 写入 `copyReview.preferredTitle = "最后一抹霞光"`。
- 新增第一版情绪标题规则：
  - 美食相关素材词命中后，优先给出“辣炒的味蕾”。
  - 晚霞相关素材词命中后，优先给出“最后一抹霞光”。
- 标题生成顺序调整为：情绪标题优先，素材关键词标题兜底。
