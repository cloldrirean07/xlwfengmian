# 案例选择可用性校验闭环实现记录

## 基本信息

- 日期：2026-07-21
- 阶段：PI Engine 维护模式 / 案例复盘字段规则补齐
- 对应 PRD：`docs/prd/AI封面创意助手_MVP重做_主路径与工作台重做.md` 的 `5.5.字段规则与校验`、`5.8.功能异常场景`
- 实现范围：`apps/web`

## 需求映射

| PRD 要求 | 当前实现 |
| --- | --- |
| 案例选择必填 | `validateExistingCaseSelection` 对空 `caseId` 返回“请选择需要复盘的案例” |
| 仅支持选择系统已有案例 | 案例库动作执行前，基于 `ensureAvailableCases()` 返回的系统案例集合校验 |
| 案例不存在或已失效提示 | 校验失败时提示“案例不可用，请刷新后重试”，不继续执行后续动作 |
| 案例读取失败提示 | 案例集合读取失败时提示“案例读取失败，请重试”，页面保留入口 |
| 导出失败提示 | Obsidian 回填工作单导出失败时提示“导出失败，请重试”，不清空当前复盘内容 |

## 修改边界

- 未新增案例选择控件，复用现有真实案例概览卡片中的动作按钮作为案例选择入口。
- 未新增接口、字段或权限规则。
- 未改变真实案例排序、筛选、回填预览、同步预览和导出结果结构。

## 验证口径

- 语法检查：`node --check public/app/createApp.js`
- 单元测试：`npm test`
- 静态服务检查：确认运行态脚本包含案例选择校验函数、案例不可用提示、案例读取失败提示和导出失败提示。

## 结论

[事实] 案例复盘入口已在动作执行前完成案例可用性校验，失效案例不会进入同步、回填或导出链路，符合 PRD 对案例选择字段和异常提示的约束。
