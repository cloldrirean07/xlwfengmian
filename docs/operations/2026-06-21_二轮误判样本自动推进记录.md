## 为什么这一步重要

- 人工勾选的误判记录第一次真正进入下游导出

## 当前验证

- `npm test`
- `npm run report:reviewed-misclassified`
- `npm run export:obsidian-reviewed-misclassified`

## 当前结果说明

- 如果没有记录同时满足 `review_status=misclassified` 与 `should_export_to_misclassified=yes`，导出结果会是空清单。
- 这是符合预期的保护行为，不会把未确认的记录误推进。
