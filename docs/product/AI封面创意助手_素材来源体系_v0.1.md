# AI封面创意助手_素材来源体系 v0.1

- 生成时间：2026-08-10
- 文档目的：把“创意参考素材库”正式纳入产品定义，明确它与用户素材、平台样本、案例库之间的关系。

## 1. 背景判断

[事实] 项目早期追问中已经确认：用户常见封面素材来源大概是优质素材库；用户也常通过内容截图、已有图片或个人素材进入流程。

[事实] 项目完整介绍中已定义案例体系：广告灵感案例、平台优质封面案例、真实案例和人工复盘记录。

[推断] “创意参考素材库”应作为独立素材来源层存在，用来补足用户没有明确参考图、现有素材不够强、平台样本不足时的创意方向。

## 2. 素材来源四层结构

```text
用户自己的素材
-> 平台热门封面样本
-> 创意参考素材库
-> 经典广告创意案例
```

### 2.1 用户自己的素材

用户主动提供的内容相关素材。

典型来源：

- 实拍照片
- 内容截图
- 产品图
- 口播画面
- 手机相册里的内容相关图片

主要作用：

- 判断这条内容已有画面能不能直接做封面。
- 判断是否需要裁切、补图或做概念重构。
- 帮用户把真实内容和封面方向绑定起来。

### 2.2 平台热门封面样本

来自小红书、抖音等平台的同类热门封面与标题。

典型来源：

- 同领域热门笔记封面
- 同话题高赞视频封面
- 相近内容类型的标题与视觉结构
- 平台原生案例记录

主要作用：

- 识别平台上更容易被点开的表达习惯。
- 提炼标题结构、封面大字、构图和颜色倾向。
- 防止产品建议脱离真实平台语境。

### 2.3 创意参考素材库

用于提供视觉灵感和创意构图参考的高质量视觉素材集合。

典型来源：

- 优质摄影作品集
- 摄影师作品页
- 海报设计作品
- 视觉构图参考
- 品牌大片与广告视觉
- 高质量情绪图、场景图、主体图参考

主要作用：

- 当用户没有明确参考图时，帮助生成方向感。
- 当用户素材普通时，提供更高级的构图、光影、主体关系和视觉氛围参考。
- 支撑“建议补图”“做创意概念图”等路径。
- 让封面建议不只像平台模板，也能有更强的视觉创意来源。

### 2.4 经典广告创意案例

用于拆解成熟创意表达和点击心理的案例层。

典型来源：

- 经典广告案例
- 创意广告奖项案例
- 品牌传播案例
- 专业人士对广告亮点的拆解
- 广告创作者的原始表达和行业评价

主要作用：

- 提炼反差、悬念、冲突、结果感、质感等创意机制。
- 作为规则系统和案例库的高质量样本。
- 帮助产品避免只凭个人审美判断。

## 3. 与现有产品链路的关系

### 3.1 在输入阶段

用户可以上传自己的素材，也可以只填写内容主题和素材描述。

当用户没有参考图，或现有素材较弱时，系统可以提示后续进入“创意参考素材库”路径。

### 3.2 在方向判断阶段

系统先判断内容更适合哪类点击机制，再决定素材来源建议：

- 素材可直接使用：优先优化当前图。
- 素材需要裁切：给出主体突出和标题区建议。
- 素材不够贴内容：建议补平台同类样本或创意参考图。
- 素材缺失：优先从创意参考素材库中找视觉方向。

### 3.3 在结果输出阶段

方向卡中可以逐步加入“参考来源类型”：

- 当前素材优化
- 平台样本借鉴
- 创意参考素材库
- 广告创意拆解

这能让用户理解：这张封面方案为什么是这个方向，不只是随机生成。

## 4. MVP 内外边界

### MVP 当前阶段

当前阶段先不做完整素材库检索和版权管理，只在产品定义、案例标注和后续规划中明确素材来源体系。

MVP 阶段的素材库目标不是“大而全”，而是先建立 20-40 条能训练判断的小而精样本，用来验证：

- 什么内容适合什么封面方向。
- 什么素材可以直接优化。
- 什么素材需要裁切或补图。
- 什么场景应该进入创意概念图路径。

扩充来源可参考：

- `AI封面创意助手_创意参考素材库扩充备选_v0.1.md`

当前已形成的 MVP 样本表结构和第一批采集清单：

- `AI封面创意助手_MVP素材样本标注表结构_v0.1.md`
- `apps/web/data/creative-reference-library/schema.v0.1.json`
- `apps/web/data/creative-reference-library/mvp-seed-batch.v0.1.json`

### 后续增强阶段

后续可以逐步实现：

1. 建立创意参考素材库目录结构。
2. 为每张参考图标注风格、主体、构图、情绪和适用场景。
3. 在方向卡中显示参考来源类型。
4. 支持用户按风格选择参考方向。
5. 将优质摄影作品、海报、广告案例拆成可复用创意模板。

## 5. 关键原则

1. 创意参考素材库不是直接复制素材，而是提炼构图、视觉风格和点击机制。
2. 用户自己的素材仍是主输入，创意参考素材库是补强路径。
3. 平台热门样本解决“像平台”，创意参考素材库解决“有质感、有创意”。
4. 经典广告案例解决“创意机制和判断依据”，不直接等于封面素材。
5. 所有参考素材都应保留来源、类型、适用场景和使用边界。
