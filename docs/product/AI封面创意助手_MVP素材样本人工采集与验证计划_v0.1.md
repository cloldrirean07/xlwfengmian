## 1. 当前正确顺序

[事实] 当前项目不应直接进入素材采集 Agent 开发，而应先建立能训练产品判断的小样本标准。

执行顺序如下：

```text
人工收集 20-40 条小而精样本
-> 人工精标 6-10 条形成标准答案
-> 用当前 MVP 跑 real-002 / real-003 / 新样本
-> 对比系统输出与人工判断差异
-> 把稳定流程抽象成 Agent
```

## 2. 阶段一：人工收集 20-40 条小而精样本

### 2.1 目标

先收集少量高质量样本，不追求数量，不做大规模抓取。

每条样本必须能训练至少一种判断：

- 封面方向判断：更清楚重点 / 更有收获感 / 更让人想点开 / 更有冲击力 / 更高级专业。
- 素材动作判断：可直接使用 / 建议裁切优化 / 建议补图 / 仅作内容参考 / 做创意概念图。
- 参考来源判断：当前素材优化 / 平台样本借鉴 / 创意参考素材库 / 广告创意拆解。

### 2.2 第一批建议配比

```text
当前素材优化：4-8 条
平台热门封面样本：8-12 条
创意参考素材库：6-10 条
广告创意案例：4-8 条
```

### 2.3 采集最小要求

每条样本先补齐：

1. 来源链接或本地截图路径。
2. 内容主题。
3. 素材描述。
4. 内容目标。
5. 为什么值得纳入样本库。
6. 不可复制边界。

### 2.4 第一批 P0 采集对象

优先从 `mvp-seed-batch.v0.1.json` 中选择以下样本：

## 3. 阶段二：人工精标 6-10 条形成标准答案

### 3.1 目标

从第一批样本中选 6-10 条做人工精标，形成“标准答案”。这批标准答案是后续规则、测试和 Agent 的学习对象。

### 3.2 精标字段

每条精标样本必须补齐：

- `sourceUrlOrPath`
- `contentScene`
- `subScene`
- `visualSubject`
- `compositionPattern`
- `titleZone`
- `emotionMood`
- `coverDirectionFit`
- `assetActionFit`
- `borrowablePoints`
- `doNotCopyBoundary`
- `clickMechanism`
- `riskNotes`
- 人工优选标题
- 人工判断理由

### 3.3 标准答案格式

每条标准答案建议包含：

```text
样本 ID：
来源：
内容主题：
素材描述：
内容目标：
人工推荐封面方向：
人工推荐素材动作：
人工优选标题：
为什么这样判断：
系统容易误判的地方：
不可复制边界：
```

## 4. 阶段三：用当前 MVP 跑真实样本

### 4.1 输入样本

第一轮至少跑：

- `real-002`：美食螃蟹与辣炒鱿鱼
- `real-003`：夏日晚霞
- 新增 P0 样本 2-4 条

### 4.2 跑法

每条样本在当前 MVP 中执行：

1. 加载或手动输入内容主题。
2. 输入素材描述和内容目标。
3. 上传或记录素材路径。
4. 生成首轮方向卡。
5. 记录系统给出的标题候选、封面方向和素材动作建议。
6. 选择人工优选标题。
7. 写回验证记录。

## 5. 阶段四：对比系统输出与人工判断差异

### 5.1 对比维度

每条样本至少比较：

- 系统封面方向是否与人工判断一致。
- 系统素材动作是否正确。
- 标题是否抓住真实素材关键词。
- 标题是否体现内容目标。
- 标题是否适配平台。
- 是否出现空泛、模板化、过度夸张或不贴素材的问题。

### 5.2 差异分级

| 等级 | 含义 | 后续动作 |
| --- | --- | --- |
| A | 系统判断基本可用 | 纳入通过样本 |
| B | 方向可用，但标题或理由需要微调 | 补规则或标题风格库 |
| C | 判断偏离明显 | 建立规则修订任务 |
| D | 输入不足导致无法判断 | 补字段或改输入表单 |

## 6. 阶段五：抽象成 Agent

### 6.1 Agent 开发条件

只有当以下条件满足后，才进入 Agent：

1. 已有 20-40 条样本位。
2. 已有 6-10 条人工精标标准答案。
3. 至少完成 real-002、real-003 和 2-4 条新增样本快跑。
4. 已整理 3 类以上稳定差异模式。
5. 已能明确哪些动作适合自动化，哪些仍需要人工判断。

### 6.2 第一版 Agent 范围

第一版 Agent 不做“自动替用户决策”，只做辅助：

- 根据样本链接或截图路径预填标注字段。
- 初步判断素材来源类型。
- 初步提取视觉主体、构图、情绪和标题区。
- 给出 2-3 个可能的标题风格。
- 输出需要人工确认的字段。

### 6.3 暂不做

- 不做全网大规模抓取。
- 不做自动发布。
- 不做无人工确认的正式入库。
- 不做直接复制外部素材。
- 不做版权授权判断。
