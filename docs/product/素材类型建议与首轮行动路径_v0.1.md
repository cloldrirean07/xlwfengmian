# 素材类型建议与首轮行动路径 v0.1

## 文档目的

这份文档记录：为什么在 `图片上下文` 已经接入分析链路之后，下一步要继续补 `素材类型建议` 和 `首轮行动路径`，而不是停留在“系统能解释”这一步。

你前面的目标一直很明确：

- 不只是给用户一些泛建议
- 而是要更像专业顾问
- 让用户知道下一步具体该先做什么

所以这一轮的核心，是把首轮结果从“解释型”往“可执行型”推进。

## 这些字段解决什么问题

### 1. 系统开始回答“你这次到底算什么素材类型”

用户自己填的 `userAssetType` 未必总是最准确。

例如：

- 用户说自己只有想法
- 但其实已经上传了截图
- 或者描述里已经明显像“人像 / 场景图 / 商品图”

当前系统会先给出一个 `suggestedAssetType`，作为分析层自己的判断。

这不一定强制覆盖用户输入，但会让系统的解释更稳定，也为后续做自动纠偏留出空间。

### 2. 系统开始明确回答“你现在先做哪一步”

过去首轮结果更偏向：

- 哪张卡适合
- 为什么适合

现在开始补一层真正的执行判断：

- `先优化现有图`
- `先补贴内容的图`
- `先做概念图`

这层很关键，因为对真实创作者来说，下一步该怎么动手，比抽象解释更重要。

### 3. 每条候选路径都有统一可读标签

`executionTag` 的意义是让候选路径不只是长段解释，而是先有一个稳定的动作标签。

这样后续不管是：

- 前端做视觉突出
- 统计哪类路径更常被选中
- 让模型引用这些动作

都会更容易。

## 当前规则怎么判断素材类型建议

当前仍然是轻量规则，不是视觉识别。

系统会综合看：

- `userAssetType`
- `assetDescription`
- `assetNotes`
- `assetContext.fileName`
- `assetContext.dimensionsLabel`

并尝试判断更像：

- `截图`
- `人像`
- `场景图`
- `商品图`
- `无图只有想法`

当前的设计重点不是做得“智能得像模型”，而是先形成一套稳定、可扩展的接口。

## 当前规则怎么判断首轮行动路径

当前判断集中在三条主路径：

### 1. 先优化现有图

适合：

- 当前已经带图
- 已经有截图或基础素材
- 当前最省成本的路径是围绕现有画面做提炼

### 2. 先补贴内容的图

适合：

- 主题明确
- 现有素材不够强
- 问题更多是“图不贴内容”

### 3. 先做概念图

适合：

- 当前没有可用现成图
- 更偏创意 / 抓眼 / 冲击
- 更需要先确定一个能承载点击机制的主体

## 当前前端已经怎么展示

在首轮结果总览里，当前已经会展示：

- `素材类型建议`
- `首轮行动路径`

在每张卡片里，也已经会展示：

- `素材类型建议`
- `建议先做什么`
- `这张卡当前最建议的执行路径`

这意味着首轮结果已经不只是“哪张卡更好”，而是开始回答：

- 你这次素材应如何理解
- 你该先怎么动手

## 当前故意没有做什么

这一版仍然没有做：

- 真正的素材类型自动纠错 UI
- 用户点击修改建议后的回流
- 根据行动路径直接触发不同流程
- 根据行动路径跳到不同工作台

这些都是后续很适合继续扩的方向，但不该在当前一轮里一起做完。

## 为什么这一层值得现在就做

### 1. 它让首轮结果开始真正可执行

没有这层时，用户看懂了也不一定知道下一步怎么做。

有了这层后，结果更像：

- 先判断
- 再给执行方向

### 2. 它给后续分支流程留下接口

以后可以很自然地扩成：

- 如果是 `先优化现有图`，就进入截图裁切 / 重点提炼流程
- 如果是 `先补贴内容的图`，就进入找图推荐流程
- 如果是 `先做概念图`，就进入概念主体生成流程

这正符合你要的“提前给后续留空档”的要求。

### 3. 它让产品更像专业工具，而不是通用 AI

通用 AI 往往会给一堆建议，但不告诉你先做哪一步。

而这次补的，就是产品经理视角里很关键的一层：

- 明确判断
- 明确动作
- 明确优先顺序
