# 平台案例批量复核看板说明 v0.1

## 目标

这份能力是给你后续做真实产品推进用的，不只是“看一个案例”，而是站在项目管理视角看一批平台案例当前到了哪一步。

它解决的是 3 个问题：

- 当前有哪些平台案例仍然几乎没填
- 哪些平台案例优先补，补什么最值
- 哪些平台案例已经接近可以进入 sync

## 当前脚本

- `npm run report:platform-case-batch-review`
  在代码仓库中生成批量复核 JSON 和 Markdown 底稿。
- `npm run export:obsidian-platform-batch-review`
  把批量复核 Markdown 包装成可继续编辑的 Obsidian 草稿。

## 输出位置

代码仓库：

- `apps/web/outputs/reports/platform-case-batch-review/platform-case-batch-review.json`
- `apps/web/outputs/reports/platform-case-batch-review/platform-case-batch-review.md`

Obsidian：

- `05_验证与实验/平台案例批量复核看板/已生成记录/`

## 当前看板字段

- 平台案例总数
- 待回填 / 部分回填 / 可进入同步 数量
- 优先处理的案例列表
- 每个案例的完整度状态
- 每个案例当前映射的真实案例数
- 每个案例的优先补字段
- 如果已有 sync preview，则展示可能变化字段

## 为什么这一步重要

- 你后面不止会有一个 `P-01`
- 当案例变多以后，不做批量看板，就会重新回到手工追踪
- 这套看板是后续接 `规则质量检查`、`回填优先级算法`、`复核历史记录` 的基础层
