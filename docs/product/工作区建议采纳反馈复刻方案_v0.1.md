## 3. 本次选定的小需求

需求名称：

**工作区建议采纳反馈**

需求目标：

在首轮方向卡后的工作区建议区增加轻量反馈闭环，使用户能够标记建议是否采纳，并为后续二轮反馈或中间状态保存留下清晰入口。

选择原因：

1. 它接在现有“工作区内下一轮建议”之后，符合当前项目自然演进。
2. 范围足够小，不需要重做首页、视觉系统或完整信息架构。
3. 能完整练习“方案确认 -> 规格 -> 维护模式实现 -> 测试验证 -> 复盘记录”的闭环。
4. 它能让工作区从“生成建议”进一步变成“形成可继续推进的中间决策”。
