## 1. 样本主题

口播类封面样本，覆盖自媒体口播、口播训练、剪辑教程和知识表达类内容。

这批样本共同体现了一类口播封面范式：

```text
人物主体
+ 高对比大字关键词
+ 明确结果承诺
+ 新手 / 建议 / 训练 / 流程等行动提示
+ 必要时加入前后对比
```

## 2. 视觉观察

### 2.1 视觉主体

- 人物正脸或半身。
- 人物表情、手势、眼神承担信任感。
- 标题文字通常比背景更重要。
- 部分封面会加入手机截图、前后对比图、小标签或点赞数字。

### 2.2 构图方式

主要有四类：

1. 人物居中 + 下方大标题。
2. 人物居中 + 中央压字。
3. 人物 + 对比小图，强调优化前后。
4. 多卡片横排，展示同类热门封面结构。

口播类封面不是单纯展示人物，而是用人物建立信任，用大字告诉用户能获得什么。

### 2.3 标题区位置

- 人物胸口下方。
- 画面中央。
- 顶部大字区。
- 左右分栏标题区。

标题通常使用高对比色，例如黄黑、绿白、白字黑描边。

## 3. 标题机制

这批样本的标题常见结构：

```text
对象 / 痛点 + 方法 / 结果
```

典型标题机制：

- 对象明确：新手、所有人、自媒体、口播剪辑。
- 痛点明确：不露脸、口播不自然、剪辑没流程。
- 结果明确：自然口播、镜头表现力、爆款流程、效率翻倍。
- 行动明确：建议、必看、训练、标准流程。

## 4. 人工标准答案

### 4.1 推荐封面方向

优先推荐：

- 更清楚重点
- 更有收获感

次级推荐：

- 更让人想点开

### 4.2 推荐素材动作

优先推荐：

- 建议裁切优化
- 建议补图

判断方式：

- 如果人物清楚、表情自然、背景干净：可裁切优化，直接做封面。
- 如果人物太小、背景杂乱、光线差：建议重新截取口播关键帧或补一张更干净的人像图。
- 如果内容是教程但没有人物素材：可用“人物 + 大字标题 + 前后对比”的平台样本结构做参考。

### 4.3 适合训练的判断

这批样本适合训练：

1. 口播截图能不能直接作为封面。
2. 人物主体是否足够清楚。
3. 标题区是否会遮挡人物五官。
4. 标题是否表达具体结果，而不是只写抽象概念。
5. 什么时候需要加前后对比。
6. 什么时候需要补拍或补图。

## 5. 可借鉴点

- 人物居中增强信任感。
- 大字关键词让内容一秒看懂。
- 使用黄黑、绿白等高对比标题提高可读性。
- 用“建议所有人”“新手必看”“标准流程”明确适用对象。
- 用前后对比强化结果感。
- 用下方大标题区承接核心利益点。

## 6. 不可复制边界

- 不复制人物肖像。
- 不照搬原标题。
- 不制造过度承诺，例如“绝杀”“暴涨”必须有内容支撑。
- 不把所有口播封面都做成夸张大字。
- 不让标题遮挡人物眼睛、嘴部和关键表情。

## 7. 与当前 MVP 的关系

这批样本用于训练当前 MVP 的素材动作判断：

- 用户上传口播截图时，系统应判断是否适合直接使用。
- 如果截图可用，应建议裁切人物主体，并保留标题区。
- 如果截图弱，应建议补拍、补图或使用更清晰的关键帧。
- 标题建议应围绕“对象 + 痛点 + 结果”，而不是只写口播两个字。

## 8. 可迁移标题方向

针对口播类内容，可以生成：

```text
新手口播先改这 3 个问题
口播不自然，先练这一套
把普通口播截图改成封面
不露脸也能做清楚的口播封面
一张图看懂口播封面怎么排
```

## 9. 系统容易误判的地方

- 只识别“人物”，没有识别口播教程场景。
- 只生成“提升表达力”这类抽象标题。
- 忽略人物和标题遮挡关系。
- 忽略前后对比对教程类封面的帮助。
- 把平台样本的夸张词照搬到用户内容里。

## 10. 后续验证问题

后续用当前 MVP 跑口播类新样本时，需要观察：

1. 是否能判断人物截图是否可直接使用。
2. 是否能提出裁切人物主体和留标题区。
3. 标题是否包含具体对象、痛点或结果。
4. 是否能避免空泛表达。
5. 是否能根据素材质量建议补拍或补图。
