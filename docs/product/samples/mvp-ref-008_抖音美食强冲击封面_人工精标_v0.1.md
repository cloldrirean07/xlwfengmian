## 1. 样本主题

抖音美食强冲击封面样本，覆盖烧烤、夜宵、红油菜品、海鲜、街头美食和探店内容。

这批样本共同体现了一类短视频美食封面范式：

```text
食物主体极大
+ 红橙高饱和
+ 烟雾 / 火光 / 油光
+ 粗大高对比标题
+ 强观看理由
```

## 2. 视觉观察

### 2.1 视觉主体

- 烤串、牛肋排、虾、海鲜、红油菜品。
- 食物通常被放到画面非常大。
- 烟雾、炭火、油光、辣椒和酱汁强化现场感。
- 部分封面加入人物探店反应，增强信任和情绪。

### 2.2 构图方式

主要有三类：

1. 食物近景占满画面。
2. 食物现场画面 + 粗大关键词压字。
3. 信息流双列截图中，用强色彩和短标题抢注意力。

强冲击封面不是“文字越大越好”，而是食物主体本身必须足够有冲击力。

### 2.3 标题区位置

- 画面中央大字区。
- 食物暗部区域。
- 上方封面标题区。
- 底部视频文案区。

标题需要短、狠、直接，但不能遮挡食物最有食欲的部位。

## 3. 标题机制

这批样本适合的标题结构：

```text
强感受 / 强场景 + 具体食物
```

可用标题机制：

- 感官冲击：视觉冲击、滋冒油、太香了、好吃程度。
- 场景钩子：深夜街头、夜宵、烧烤、探店。
- 好奇钩子：谁懂、看到这个你想到了谁、不能只我一个人看。
- 食物钩子：牛肋排、烧烤、海鲜、红油、辣味。
- 行动钩子：发给朋友、收藏、想吃谁做的。

## 4. 人工标准答案

### 4.1 推荐封面方向

优先推荐：

- 更有冲击力

次级推荐：

- 更让人想点开

### 4.2 推荐素材动作

优先推荐：

- 平台样本借鉴
- 建议裁切优化

判断方式：

- 如果食物主体够大、颜色够强、油光明显：建议直接裁切强化主体。
- 如果食物图普通但内容是探店或夜宵：建议补强近景、烟火气或红橙调色。
- 如果素材缺少食物特写：不建议硬做强冲击，容易标题党。
- 如果是教程类内容：标题要保留教程价值，不能只写感官刺激。

### 4.3 适合训练的判断

这批样本适合训练：

1. 什么美食图适合走“强冲击”方向。
2. 红橙高饱和和烟火感是否足够支撑点击。
3. 标题是否有具体食物和具体场景。
4. 强冲击标题是否过度标题党。
5. 食物近景和标题区是否互相遮挡。
6. 短视频封面和图文封面的差异。

## 5. 可借鉴点

- 食物主体放大到一眼可识别。
- 用红油、火光、烟雾和油光制造感官刺激。
- 标题用粗体和高对比色提高信息流可读性。
- 用“谁懂”“深夜”“看到就想吃”等短视频语言制造观看理由。
- 用视频时长和动作画面强化真实感。

## 6. 不可复制边界

- 不复制平台截图和原视频封面。
- 不照搬原标题。
- 不夸大食物体验。
- 不把普通美食图强行包装成冲击感。
- 不让大字遮挡食物主体。

## 7. 与 real-002 的关系

`real-002` 是螃蟹和辣炒鱿鱼的真实用户素材。

这批样本可以帮助 `real-002` 判断：

- 是否适合走“辣炒海鲜强冲击”方向。
- 是否需要裁切突出红油、蟹壳、鱿鱼和辣椒。
- 标题是否应该加入“辣炒”“海鲜”“下饭”“夜宵”等具体词。

对 `real-002` 的启发标题方向：

```text
辣炒海鲜封面要先抓住这一口
普通海鲜图怎么做出冲击感
红油和海鲜，是这张封面的点击点
一眼想点开的辣炒海鲜封面
```

## 8. 系统容易误判的地方

- 只识别“美食”，没有识别“强冲击”。
- 只生成“太香了”这类空泛感叹。
- 忽略食物主体是否足够大。
- 忽略真实内容是 AI 封面教程，不是单纯探店视频。
- 把强冲击等同于标题越夸张越好。
