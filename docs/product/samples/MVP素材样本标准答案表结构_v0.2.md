## 1. 这张表解决什么问题

MVP 阶段不追求大规模素材库，而是先建立一批小而精的标准答案样本，用来训练和验证系统是否更会判断封面方向。

这张表的作用是统一后续样本采集和人工标注口径，避免样本越收越多，但无法判断系统输出是否变好。

## 3. 标准答案判定口径

每条样本最终要能回答 6 个问题：

1. 这张素材最适合哪个封面方向。
2. 它是可直接用、需要裁切、需要补图，还是只能做参考。
3. 它真正可借鉴的是画面结构、标题机制、色彩氛围，还是点击理由。
4. 它不能复制什么。
5. 如果用户上传类似素材，系统应该给出什么标题和画面动作。
6. 系统输出偏离标准答案时，应该修规则、修标题库，还是修 UI 展示。

## 4. 推荐收集配比

| 样本类型 | 数量 | 用途 |
| --- | ---: | --- |
| 用户当前素材 | 8-10 条 | 判断真实素材是否可用、是否需要补图 |
| 平台热门样本 | 8-12 条 | 学习平台封面结构、标题机制和点击诱因 |
| 创意参考素材库 | 4-8 条 | 学习构图、光影、色彩和高级质感 |
| 广告创意案例 | 2-4 条 | 学习反差、记忆点和视觉创意机制 |
