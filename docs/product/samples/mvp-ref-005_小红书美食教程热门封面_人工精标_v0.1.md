## 1. 样本主题

小红书美食教程 / 家常菜合集 / 下饭菜 / 减脂餐 / 空气炸锅菜谱封面。

这批样本共同体现了一类小红书美食封面范式：

```text
多图食物主体
+ 高密度食欲画面
+ 大字利益点标题
+ 数量或结果承诺
+ 强收藏理由
```

## 2. 视觉观察

### 2.1 视觉主体

- 多道成品菜。
- 食物近景。
- 红油、酱汁、辣椒、葱花、香菜等高刺激视觉元素。
- 部分样本使用白碗、黑盘、空气炸锅、餐桌等生活化容器。

### 2.2 构图方式

主要有三类：

1. 九宫格或多宫格合集。
2. 单张食物近景大图。
3. 设计化菜谱清单图。

其中九宫格和多宫格样本最适合训练“合集型封面”，单张食物近景适合训练“裁切强化食欲点”。

### 2.3 标题区位置

- 中央横条标题。
- 上方大字标题。
- 上下双标题。
- 食物拼图中间留白或直接压字。

标题通常不是轻提示，而是封面的主视觉之一。

## 3. 标题机制

这批样本的标题常见结构：

```text
数量 + 强评价 + 场景
```

例如：

- 九个超级好吃的下饭菜
- 十六道家常菜美食
- 九款巨好吃的家常菜
- 12 款抗炎炒菜
- 半个月不重样的晚餐
- 分享我经常吃的 16 款减脂餐

可提炼的标题机制：

- 数量感：让内容显得具体、丰富、可收藏。
- 场景感：下饭菜、晚餐、家常菜、减脂餐。
- 结果感：米饭不够吃、全家好评、学会半个月不从样。
- 健康感：抗炎、轻油低盐、减脂。
- 行动感：收藏起来、照着做。

## 4. 人工标准答案

### 4.1 推荐封面方向

优先推荐：

- 更有冲击力
- 更有收获感

次级推荐：

- 更清楚重点

### 4.2 推荐素材动作

优先推荐：

- 平台样本借鉴
- 建议裁切优化

当用户只有单张菜品照片时：

- 如果食物主体清楚、颜色强烈：可直接使用，并建议裁切强化主体。
- 如果菜品普通、缺少标题区：建议补同类平台样本或做合集型封面。

### 4.3 适合训练的判断

这批样本适合训练：

1. 美食素材是否具备食欲冲击点。
2. 单图是否适合改成合集型封面。
3. 标题是否需要引入数量、场景和结果承诺。
4. 美食教程类内容是否应该强调“可收藏、可照做”。
5. 用户真实素材和平台热门封面之间的差距在哪里。

## 5. 可借鉴点

- 用多宫格制造“内容很多、值得收藏”的感觉。
- 用大字标题快速说明内容收益。
- 用红、橙、黄、绿色点缀制造食欲刺激。
- 用“数量 + 场景 + 结果”增强点击理由。
- 将标题压到中心区域，降低用户理解成本。

## 6. 不可复制边界

- 不复制原图。
- 不照搬原标题。
- 不机械套用“几款”“半个月不重样”“全家好评”等高频模板。
- 不为了冲击力牺牲真实内容准确性。
- 不把所有美食内容都做成九宫格，单菜教程和探店内容仍需看素材目标。

## 7. 与 real-002 的关系

`real-002` 是螃蟹和辣炒鱿鱼的真实用户素材。

这批样本可以帮助 `real-002` 判断：

- 是否应该从单张食物图升级为“海鲜下饭菜 / 辣炒海鲜教程”方向。
- 是否需要标题加入数量感或结果感。
- 是否要裁切突出红油、蟹、鱿鱼等食欲主体。
- 标题是否应避免过虚，优先表达具体食材和点击收益。

对 `real-002` 的启发标题方向：

```text
辣炒海鲜这样做更有食欲
一眼想收藏的辣炒海鲜封面
把普通美食图改成下饭菜封面
```

## 8. 系统容易误判的地方

- 只识别为“美食”，没有识别“教程 / 合集 / 收藏”。
- 只生成好吃、香、馋等情绪词，缺少结果承诺。
- 直接模仿平台标题，导致标题同质化。
- 忽略用户素材是否真的适合九宫格。
- 忽略标题区和主体遮挡关系。

## 9. 后续验证问题

用当前 MVP 跑 `real-002` 时，需要观察：

1. 是否能给出“更有冲击力 / 更有收获感”的方向。
2. 是否能提出“裁切突出红油和海鲜主体”的建议。
3. 标题候选是否包含真实食材关键词。
4. 标题是否能体现教程或收藏价值。
5. 是否能避免空泛标题。
