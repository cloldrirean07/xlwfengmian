## 1. 样本主题

生活方式随手拍样本，覆盖人像、日常拼图、城市散步、餐食、健身、宠物、旅行和生活碎片。

这批样本共同体现了一类高频用户输入：

```text
素材有氛围
+ 画面有生活感
+ 但内容任务不一定清楚
+ 需要标题和主题把它拉成封面
```

## 2. 视觉观察

### 2.1 视觉主体

- 人像随拍。
- 猫、餐食、咖啡、窗景、健身房、街景。
- 四宫格或多图生活碎片。
- 阳光、树影、低饱和色、胶片感和松弛状态。

### 2.2 构图方式

主要有三类：

1. 单张人像氛围图。
2. 四宫格生活拼图。
3. 日常物件和场景碎片组合。

单张人像适合做生活方式、穿搭、情绪类封面；四宫格拼图适合做日记、城市散步、生活复盘类封面；物件碎片适合做氛围参考，但不一定能承载清晰教程。

### 2.3 标题区位置

- 单图：下方留白、暗部区域、人物旁边空区。
- 四宫格：中心小字、角落短句、单格留白。
- 人像近景：标题不能遮挡五官。

## 3. 标题机制

这批样本适合的标题不是强销售式，而是轻内容任务：

```text
状态 / 场景 + 具体主题
```

可用标题机制：

- 场景：周末、散步、通勤、咖啡、健身、出片。
- 状态：松弛感、随手拍、生活碎片、今日状态。
- 任务：穿搭记录、拍照姿势、生活复盘、城市散步、日常灵感。
- 钩子：普通照片怎么做封面、随手拍如何变高级、生活图怎么配标题。

## 4. 人工标准答案

### 4.1 推荐封面方向

优先推荐：

- 更清楚重点
- 更让人想点开

次级推荐：

- 更高级专业

### 4.2 推荐素材动作

按素材情况分：

- 人物清楚、光线好、有留白：建议裁切优化。
- 氛围强但主题弱：仅作内容参考，需要补标题任务。
- 内容目标是教程、产品种草、方法论：建议补图或补更明确的主体。
- 多图生活拼图：可做情绪型封面，但必须增加具体主题。

### 4.3 适合训练的判断

这批样本适合训练：

1. 日常照片有没有明确视觉主体。
2. 氛围图是否能直接做封面。
3. 什么时候需要通过标题补内容任务。
4. 什么时候需要补图。
5. 生活方式素材如何避免空泛。
6. 多图拼图如何形成叙事而不是堆照片。

## 5. 可借鉴点

- 自然光和低饱和色带来的生活质感。
- 人像状态带来的信任和亲近感。
- 四宫格拼图带来的“生活切片”叙事。
- 留白和暗部区域适合承接轻标题。
- 松弛感适合生活方式、穿搭、旅行、日常复盘内容。

## 6. 不可复制边界

- 不复制人物肖像和平台原图。
- 不把“好看”当作封面成立的理由。
- 不输出只有氛围、没有内容任务的标题。
- 不强行把生活照包装成教程或产品种草。
- 不让标题遮挡人物五官和主要动作。

## 7. 与当前 MVP 的关系

这批样本用于训练当前 MVP 的素材动作判断：

- 用户上传日常图时，系统要先判断主体和内容目标是否匹配。
- 如果只有氛围，系统应提示补主题或补图。
- 如果人像质量好，系统应建议裁切和标题区。
- 如果是生活拼图，系统应引导用户明确“记录什么”或“想让人点开什么”。

## 8. 可迁移标题方向

针对生活方式随手拍，可以生成：

```text
普通随手拍也能做成封面
这类生活图适合这样配标题
把日常照片变成小红书封面
松弛感照片别只写随手拍
生活拼图要先给一个主题
```

## 9. 系统容易误判的地方

- 只识别“人像好看”，没有判断内容目标。
- 把所有生活图都推荐为“高级感”。
- 生成空泛标题，例如“记录美好生活”。
- 忽略图片是否有标题区。
- 忽略单图和拼图的封面策略差异。

## 10. 后续验证问题

后续用当前 MVP 跑生活方式新样本时，需要观察：

1. 是否能判断素材和内容目标是否匹配。
2. 是否能区分“可直接裁切”和“仅作氛围参考”。
3. 是否能提醒补标题任务或补图。
4. 是否能避免空泛生活文案。
5. 是否能给出适合小红书的轻标题结构。
