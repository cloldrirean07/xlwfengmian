## 1. 样本主题

晚霞、天空、云层、落日、城市傍晚和天空调色参考。

这批样本共同体现了一类风景情绪封面范式：

```text
大面积天空留白
+ 强色彩渐变
+ 云层方向感
+ 地平线或剪影压底
+ 短标题承接情绪
+ 内容任务补足点击理由
```

## 2. 视觉观察

### 2.1 视觉主体

- 晚霞和云层。
- 橙、粉、蓝、紫色天空渐变。
- 城市楼体、道路、山体、海面或树影作为底部压线。
- 部分样本使用九宫格收集同类天空情绪。
- 部分样本展示原片和调色后对比。

### 2.2 构图方式

主要有四类：

1. 天空占据 70% 以上画面，地面作为底部剪影。
2. 云层形成斜向或横向流动，制造视觉张力。
3. 九宫格天空合集，制造“收藏一组晚霞”的感觉。
4. 原片 / 调色后对比，突出封面优化空间。

风景封面的重点不是“把风景拍美”，而是给美景一个清晰的内容任务。

### 2.3 标题区位置

- 天空留白区。
- 暗部地平线区域。
- 云层低干扰区域。
- 九宫格样本适合中心短句或下方轻标题。

标题应短、轻、情绪化，但不能失去内容信息。

## 3. 标题机制

这批样本适合的标题结构：

```text
情绪记忆点 + 内容任务
```

可用标题机制：

- 情绪记忆点：最后一抹霞光、夏天的云、日落前几分钟。
- 场景感：傍晚、下班路上、城市天空、旅途中。
- 内容任务：如何做封面、怎么配标题、调色前后、拍照构图。
- 点击理由：普通晚霞图如何变高级、一张天空图怎么做封面。

## 4. 人工标准答案

### 4.1 推荐封面方向

优先推荐：

- 更高级专业
- 更让人想点开

次级推荐：

- 更清楚重点

### 4.2 推荐素材动作

优先推荐：

- 创意参考素材库
- 建议裁切优化

判断方式：

- 如果天空色彩强、留白清楚：可直接裁切为情绪封面。
- 如果地面杂乱：建议裁掉底部噪音，保留天空主体。
- 如果只是普通天空照：建议参考调色、云层构图或补一张更有张力的天空图。
- 如果内容是 AI 封面教程：标题必须保留教程任务，不能只写风景诗句。

### 4.3 适合训练的判断

这批样本适合训练：

1. 风景图是否具备情绪主体。
2. 天空是否有足够标题留白。
3. 什么时候应该裁掉地面杂乱区域。
4. 标题如何在诗意和信息之间平衡。
5. 风景素材如何转成 AI 封面教程案例。
6. 调色前后对比是否能成为封面卖点。

## 5. 可借鉴点

- 大面积天空留白。
- 橙粉蓝紫的色彩层次。
- 云层流动方向带来的视觉张力。
- 地平线压底让画面稳定。
- 用短标题承接情绪，不破坏画面。
- 用“调色前后 / 封面前后”作为教程类点击点。

## 6. 不可复制边界

- 不复制摄影作品和平台原图。
- 不照搬他人的调色对比图。
- 不把所有晚霞图都写成诗句。
- 不让标题只剩情绪，没有内容任务。
- 不过度调色导致失真。

- 标题是否可以使用“最后一抹霞光”作为人工优选标题。

对 `real-003` 的启发标题方向：

```text
最后一抹霞光，适合这样做封面
普通晚霞图怎么变成封面

```

## 8. 系统容易误判的地方

- 只生成“治愈晚霞”“好美的天空”这类空泛标题。
- 忽略用户目标是 AI 封面教程。
- 忽略标题区和云层主体的遮挡关系。
- 过度追求高级感，导致点击理由不足。
- 对所有天空图都建议低文字密度，导致信息不清楚。
