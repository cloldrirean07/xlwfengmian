## 1. 改造判断

[事实] 项目定位是面向成长型内容创作者，解决发布前“封面方向、标题、配图、构图”的点击决策问题。

[事实] `real-002 / real-003` 已证明当前链路可以从真实素材说明进入方向卡、标题候选、素材动作建议。

[事实] 当前首页已经存在 `封面生成 / 案例验证 / 高级维护` 三类视图，但第一屏仍展示较多规则、案例验证、后台维护信息。

[推断] 当前最适合做的不是重写产品能力，而是重排首页体验：让创作者第一眼只看到“上传素材 -> 生成方案 -> 选方向 -> 继续优化”，把案例复盘、规则、写回保留为后台支撑。

## 2. 首页改造目标

让用户打开网页后，能在 10 秒内理解并开始使用：

1. 这个工具是做封面方案的，不是后台规则系统。
2. 用户只需要提供内容主题、平台、素材图或素材描述。
3. 系统会给 3 个可比较的封面方向。
4. 每个方向会同时给标题、封面大字、素材动作和构图建议。
5. 选中方向后可以继续二轮优化。

## 3. 不做范围

本轮不做以下内容：

- 不接真实图片视觉识别模型。
- 不重写规则系统和案例库。
- 不重做整套视觉设计系统。
- 不删除案例验证与高级维护能力。
- 不把复盘、写回、规则修订入口放在第一屏主路径里。
- 不在本轮实现完整创意参考素材库检索，只先保留素材来源体系定义。

## 4. 推荐方案

### 方案 A：主链路收口改造

将当前首页改为“创作者首页 + 后台折叠”的结构。

第一屏只保留：

- 产品名称与一句话价值
- 一个主 CTA：开始生成封面方案
- 一个轻入口：加载 real-002 / real-003 示例
- 三个结果承诺：方向、标题、素材动作

主工作区只保留：

- 素材上传
- 内容主题
- 内容目标
- 目标平台
- 素材描述
- 生成按钮

结果区突出：

- 3 张方向卡
- 每张卡的标题候选
- 封面大字
- 素材适用判断
- 下一步动作

后台区域：

- 案例验证
- Prompt / LLM Draft
- 复盘看板
- 写回工具

统一降级为“高级维护”，默认折叠或放到第二视图。

### 方案 B：完整视觉重构

重新设计一个更像正式 SaaS / H5 工具的视觉首页，重做布局、配色、卡片和动效。

优点：视觉提升明显。

风险：容易把当前已跑通的主链路打散，且需要更多测试。

### 方案 C：只改文案

只把当前页面上的后台语言改成创作者语言。

优点：成本最低。

风险：首页层级问题仍然存在，用户仍会感觉这是内部系统，而不是创作者工具。

## 5. 推荐结论

[推断] 当前应采用方案 A。

原因：

- 已有功能不是不能用，问题主要是呈现顺序不对。
- 真实案例快跑已经证明主链路可用，应把它前置为用户体验。
- 后台规则与复盘仍有价值，但不应打断创作者第一段使用。
- 方案 A 改动范围可控，适合进入下一轮代码实现。

## 6.1 素材来源体系补充

首页主链路仍以用户自己的素材为起点，但后续产品判断应能区分四类素材来源：

1. 用户自己的素材：实拍照片、截图、产品图、口播画面。
2. 平台热门封面样本：小红书、抖音等平台的同类热门封面和标题。
3. 创意参考素材库：优质摄影作品集、海报设计、品牌大片、广告视觉、构图和氛围参考。
4. 经典广告创意案例：用于拆解悬念、冲突、反差、结果感和质感等创意机制。

本轮首页改造先不露出完整素材库入口，但结果卡后续可以增加“参考来源类型”，让用户知道某个方案是基于当前素材优化、平台样本借鉴，还是创意参考素材库启发。

## 7. 首轮实现范围

### 7.1 `index.html`

建议调整：

- 第一屏弱化 “Creator MVP / 后台支撑已后移” 这类内部表达。
- 主导航从 `封面生成 / 案例验证 / 高级维护` 改为更自然的层级：
  - `开始创作`
  - `真实示例`
  - `高级维护`
- 将“案例示范快跑”移动到主工作台旁边或输入区上方，变成低成本示范入口。
- 将“保存与复盘”从主路径末尾改成折叠式高级入口，不抢占创作者注意力。

### 7.2 `styles.css`

建议调整：

- 第一屏减少装饰信息密度，突出一个主 CTA。
- 表单和结果卡使用更清晰的左右或上下分区。
- 方向卡强化标题候选、素材动作、选择按钮。
- 高级维护区域视觉上后退，不再和主工作台同等权重。

### 7.3 `renderers.js`

建议调整：

- 方向卡渲染优先展示用户决策字段：
  - 方向标签
  - 封面大字
  - 标题候选
  - 素材使用判断
  - 下一步动作
- 规则命中、风险边界、内部来源标签降级为详情信息。

### 7.4 `createApp.js`

建议调整：

- 保留真实案例加载到主工作台能力。
- 优化成功后的滚动目标：生成后直接滚到方向卡，而不是后台区域。
- 高级维护入口不自动展开，除非用户明确点击。

### 7.5 `updatelog.md`

记录本轮首页体验改造的所有文件和验证结果。

## 8. 验收标准

本轮完成后，需要满足：

1. 首页第一屏能明确表达“上传素材，生成封面方案”。
2. 用户不需要理解规则系统，也能完成首轮生成。
3. `real-002 / real-003` 可以从首页入口加载并生成方向卡。
4. 方向卡里能看到人工优选标题、素材关键词和素材动作建议。
5. 案例验证、复盘、写回仍可进入，但默认不干扰主链路。
6. 自动测试通过。
7. 本地页面可访问，主页面返回 `200`。

## 10. 下一步执行建议

下一步进入代码实现时，建议按以下顺序：

1. 先改 `index.html` 的首页结构和主路径文案。
2. 再改 `styles.css`，让第一屏和方向卡更像创作者工具。

5. 跑测试与构建。
6. 整理变更清单，确认后提交推送。

3. `参考素材标注规范`：主体、构图、情绪、光影、平台、适用内容类型。
