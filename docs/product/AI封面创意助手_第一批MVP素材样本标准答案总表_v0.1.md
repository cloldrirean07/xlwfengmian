## 3. 真实案例标准答案

### 3.1 `real-002` 美食真实案例

关联样本：

- `mvp-ref-005`：小红书美食教程热门封面。
- `mvp-ref-008`：抖音美食强冲击封面。

人工标准答案：

| 维度 | 标准答案 |
| --- | --- |
| 推荐封面方向 | 更有冲击力；更有收获感；次选更清楚重点 |
| 推荐素材动作 | 可直接使用；建议裁切优化；可参考平台美食强冲击样本 |
| 必须保留素材关键词 | 螃蟹、辣炒鱿鱼、红油、辣椒、香菜、海鲜 |
| 标题机制 | 具体食材 + 食欲感 / 教程任务 / 封面改造结果 |
| 人工优选标题 | 辣炒的味蕾 |
| 可借鉴点 | 红油色彩、食物近景、食欲冲击、下饭/夜宵/教程价值 |
| 不可复制边界 | 不能只做探店标题；不能丢掉“AI 封面制作教程”的学习价值 |

系统应该学会：

```text
这不是普通美食分享，而是“用真实美食素材做 AI 封面教程”。
方向可以借鉴强冲击和美食教程样本，但标题要同时保留食材、食欲和教程任务。
```

### 3.2 `real-003` 晚霞真实案例

关联样本：

- `mvp-ref-014`：晚霞天空摄影参考。

人工标准答案：

| 维度 | 标准答案 |
| --- | --- |
| 推荐封面方向 | 更高级专业；更让人想点开；次选更清楚重点 |
| 推荐素材动作 | 可直接使用；建议裁切优化；可参考天空留白和情绪标题样本 |
| 必须保留素材关键词 | 晚霞、云层、落日、夏日、天空 |
| 标题机制 | 情绪记忆点 + 内容任务 |
| 人工优选标题 | 最后一抹霞光 |
| 可借鉴点 | 天空留白、橙粉蓝紫渐变、云层方向感、地平线压底 |
| 不可复制边界 | 不能只写诗意风景标题；必须保留“AI 封面构思教程”的任务 |

系统应该学会：

```text
晚霞图有天然情绪优势，但封面不能只有风景美感。
标题要在“最后一抹霞光”的情绪记忆点之外，补足封面教程和构思价值。
```

## 4. 进入验证的判断标准

对每条真实案例，系统输出至少需要通过以下 6 项：

1. 方向判断是否命中人工标准答案。
2. 素材动作是否符合真实素材状态。
3. 标题是否包含真实素材关键词。
4. 标题是否体现内容目标。
5. 构图建议是否能落到具体素材。
6. 是否避免空泛、标题党或只剩情绪。
