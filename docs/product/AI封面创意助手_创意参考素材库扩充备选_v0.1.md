# AI封面创意助手_创意参考素材库扩充备选 v0.1

- 生成时间：2026-08-10
- 文档目的：记录创意参考素材库的后续可扩充来源，作为产品实现的备选池；当前 MVP 阶段不展开完整素材库，只先做“能训练判断”的小而精素材库。

## 1. 当前阶段原则

[事实] 当前 MVP 的核心目标是验证封面方向判断、标题候选、素材动作建议是否比通用 AI 更有帮助。

[推断] 因此当前不应追求素材库规模，而应优先沉淀少量高质量、可标注、可复盘、能训练判断的参考样本。

MVP 阶段只做：

- 少量平台热门封面样本
- 少量优质摄影 / 海报 / 品牌视觉参考
- 少量经典广告创意案例
- 少量真实用户素材案例

暂不做：

- 大规模爬取
- 完整素材检索系统
- 复杂版权管理
- 多平台自动同步
- 素材商业授权流程

## 2. 扩充来源备选

### 2.1 平台热门内容封面

来源示例：

- 小红书热门笔记封面
- 抖音热门视频封面
- B 站封面
- YouTube Shorts / YouTube 视频封面
- Instagram Reels / Pinterest 图文封面

主要价值：

- 学习真实平台点击习惯。
- 提炼标题区位置、封面大字、主体占比、颜色倾向。
- 判断不同平台对“信息感、结果感、悬念感、冲突感、质感”的偏好。

适合优先级：P0

### 2.2 优质摄影与视觉作品集

来源示例：

- 摄影师个人作品页
- Behance 摄影项目
- Pinterest 高质量视觉参考
- 品牌 Lookbook
- 生活方式摄影专题

主要价值：

- 提供构图、光影、色彩、主体关系和氛围参考。
- 支撑“创意参考素材库”的质感来源。
- 当用户素材普通时，为补图和概念图提供方向。

适合优先级：P1

### 2.3 海报设计与杂志封面

来源示例：

- 电影海报
- 展览海报
- 音乐专辑封面
- 时尚杂志封面
- 商业杂志封面
- 生活方式杂志专题图

主要价值：

- 学习标题层级、留白、主体突出和视觉节奏。
- 帮助封面从“截图 + 字”升级为更有设计感的视觉方案。
- 支撑高质感封面、人物封面、知识类封面的标题区设计。

适合优先级：P1

### 2.4 电商与品牌视觉

来源示例：

- 天猫 / 淘宝商品首图
- Amazon 商品图
- 品牌官网头图
- 产品详情页首屏视觉
- 新品发布视觉

主要价值：

- 学习商品主体、卖点呈现、结果感和利益点表达。
- 适合商品种草、测评、探店、生活方式内容。
- 帮助用户判断素材是否需要“产品主体更大、卖点更前置”。

适合优先级：P2

### 2.5 经典广告与创意奖项案例

来源示例：

- Cannes Lions
- D&AD
- One Show
- 品牌传播案例
- 国内广告案例拆解
- 专业人士对广告亮点的分析

主要价值：

- 拆解反差、冲突、隐喻、悬念、记忆点。
- 为规则系统提供更成熟的创意机制。
- 避免产品判断只停留在平台套路和个人审美。

适合优先级：P2

### 2.6 电影 / 剧集 / 纪录片截图

来源示例：

- 经典电影构图
- 人物特写
- 情绪场景
- 纪录片海报与截图
- 剧集宣传图

主要价值：

- 学习叙事感、悬念感、人物关系和情绪氛围。
- 适合故事类、观点类、人物类、情绪类内容。
- 帮助封面从“说明内容”升级为“制造情绪入口”。

适合优先级：P3

### 2.7 知识类内容视觉

来源示例：

- 课程封面
- 播客封面
- 电子书封面
- 知识付费海报
- 方法论信息图
- 公开课宣传图

主要价值：

- 适合知识口播、教程、方法论、清单类内容。
- 学习强信息感、结果感、可信感的封面表达。
- 帮助判断标题、结构和图像信息密度。

适合优先级：P2

### 2.8 AI 生图社区样本

来源示例：

- Midjourney 优秀作品
- Runway 视觉样本
- 即梦 / 可灵 / Liblib 等 AI 视觉社区
- 优质提示词案例

主要价值：

- 学习可生成的视觉风格、镜头语言和提示词方向。
- 为后续接入生图或改图能力做准备。
- 帮助判断哪些创意方向适合用 AI 生成，而不是只靠用户现有素材。

适合优先级：P3

## 3. MVP 小而精素材库建议

MVP 阶段建议先建立 20-40 条高质量标注样本，而不是建立大规模素材库。

推荐结构：

```text
平台热门封面样本：8-12 条
优质摄影 / 海报 / 品牌视觉：6-10 条
经典广告创意案例：4-8 条
真实用户素材案例：4-8 条
```

每条样本必须能回答：

- 它适合训练哪类封面方向判断？
- 它的主体是什么？
- 它的构图方式是什么？
- 它的标题区在哪里？
- 它的情绪氛围是什么？
- 它能借鉴什么？
- 它不能直接复制什么？

## 4. 标注字段建议

每条素材建议至少标注：

```text
素材 ID
来源类型
来源链接或本地路径
适合平台
内容场景
视觉主体
构图方式
情绪氛围
标题区位置
对应封面方向
可借鉴点
不可复制边界
适合用于哪类用户输入
```

第一版正式标注结构已落盘到：

- `AI封面创意助手_MVP素材样本标注表结构_v0.1.md`
- `apps/web/data/creative-reference-library/schema.v0.1.json`

其中第一批 MVP seed 清单包含 24 条样本位：2 条已由 real-002 / real-003 真实案例补入，22 条作为待采集样本目标。

## 5. 后续产品实现承接

后续进入产品实现时，可以分三步做：

1. 先在案例数据结构中加入 `referenceSourceType`。
2. 再在方向卡中展示“参考来源类型”。
3. 最后建立可维护的创意参考素材库目录与标注文件。

建议先支持的 `referenceSourceType`：

```text
current-asset
platform-sample
creative-reference
ad-creative-case
```

对应用户可见文案：

```text
当前素材优化
平台样本借鉴
创意参考素材库
广告创意拆解
```

## 6. 结论

[推断] 创意参考素材库可以持续扩充，但当前 MVP 阶段应该只做小而精的判断训练库。

扩充的核心不是“收集更多好看的图”，而是沉淀可复用的封面判断依据：什么内容适合什么视觉方向，什么素材应该直接优化，什么素材需要补图，什么情况应该做创意概念图。
