# 2026-08-12 mvp-ref-003 口播规则修订任务单

## 1. 修订背景

- 样本对象：`mvp-ref-003` 口播类封面样本
- 证据来源：
  - `docs/product/samples/mvp-ref-003_口播类封面样本_人工精标_v0.1.md`
  - `docs/validation/2026-08-12_mvp-ref-003_口播样本效率验证记录.md`
- 当前结论：
  - [事实] 当前 MVP 能生成三张方向卡，方向大体没有偏离人工标准答案。
  - [事实] 当前 MVP 还没有把口播封面识别为独立素材场景，标题、画面动作和构图提醒仍偏通用。
  - [推断] 口播类规则应优先补“人物主体 + 大字标题 + 对象痛点 + 方法结果 + 五官避让”的判断链，而不是继续扩充更多样本。

## 2. 待修问题

| 优先级 | 问题 | 影响 |
| --- | --- | --- |
| P0 | 口播 / 人物 / 镜头表现力 / 不露脸 / 自媒体等关键词没有稳定进入素材场景识别 | 系统会把口播截图当普通截图，方向卡缺少人物和标题区判断 |
| P0 | 标题机制没有稳定形成“对象 / 痛点 + 方法 / 结果” | 标题容易泛化成“AI、小红书封面、标题封面” |
| P0 | 画面动作没有提示人物主体、五官和标题区关系 | 创作者无法直接知道截图该怎么裁、字该放哪 |
| P1 | 风险提醒没有稳定提示遮挡五官和过度承诺 | 结果卡可执行性不足，容易做出夸张但不可信的封面 |

## 3. 规则修订范围

### 3.1 素材场景识别

新增 `talking-head` 场景，触发信号包括：

- 口播、人物、正脸、半身、表情、五官
- 镜头表现力、自媒体、训练、剪辑、流程
- 不露脸、建议、标准流程、新手

命中后应对方向排序产生影响：

- 优先支持“更清楚重点”
- 次级支持“更有收获感”
- 保留“更让人想点开”作为补充方向

### 3.2 标题风格库

新增口播类标题风格：

```text
对象 / 痛点 + 方法 / 结果
```

候选标题应优先包含：

- 口播
- 新手 / 自媒体 / 不露脸
- 自然 / 表现力 / 标准流程 / 训练

### 3.3 方向卡表达

口播样本命中后，方向卡至少应表达：

- 视觉重点：人物主体、正脸或半身、表情和手势
- 标题策略：对象、痛点、方法或结果
- 构图动作：标题放在胸口下方、侧边或背景留白区，避开五官
- 风险提醒：避免标题遮挡眼睛、嘴部和关键表情，避免“暴涨”“绝杀”等无依据承诺

## 4. 验收标准

| 验收项 | 标准 |
| --- | --- |
| 场景识别 | mvp-ref-003 输入后，方向卡出现口播人物相关信号 |
| 标题候选 | 至少 1 个标题包含“口播”，并体现对象 / 痛点 / 方法 / 结果之一 |
| 视觉动作 | 结果卡出现“人物主体”或“正脸 / 半身” |
| 构图动作 | 结果卡出现“避开五官”或“标题放在胸口下方 / 侧边” |
| 风险提醒 | 结果卡出现“遮挡五官”或“过度承诺”相关提醒 |
| 自动化测试 | 新增口播场景单测，并通过现有测试 |
