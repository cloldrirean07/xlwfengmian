## 2. 输入摘要

```text
内容主题：
用 AI 工具快速做一张小红书封面，从生活方式随手拍到标题和构图的构思选择，是关于日常生活碎片、城市散步、人像和咖啡健身记录的分享。

内容目标：
让用户一眼知道这是一篇 AI 封面制作教程，并愿意点开学习如何把普通随手拍和生活拼图做成更清楚、更有主题的小红书封面。

素材描述：
素材参考为生活方式随手拍：有人像、猫、餐食、咖啡、窗景、健身房、街景和四宫格生活拼图。画面有自然光、树影、低饱和色、胶片感和松弛状态，但内容主题不一定清楚。

参考偏好：
生活方式随手拍封面方向，突出生活感、主题任务、标题区、轻内容钩子和多图叙事，避免只有氛围没有主题，也避免标题遮挡人物五官。
```

## 3. 人工标准答案摘要

| 项目 | 人工标准答案 |
| --- | --- |
| 推荐方向 | 更清楚重点 / 更让人想点开；次级为更高级专业 |
| 标题机制 | 状态 / 场景 + 具体主题 |
| 素材动作 | 人物清楚且有留白时裁切优化；氛围强但主题弱时补标题任务；教程或种草目标需要补更明确主体 |
| 构图重点 | 单图用下方留白、暗部或人物旁边空区；四宫格用中心小字、角落短句或单格留白 |
| 关键风险 | 不把“好看”当封面成立理由；不输出空泛生活文案；标题不遮挡五官 |

## 4. 当前 MVP 输出摘要

## 6. 结论

[事实] 当前 MVP 能判断随手拍样本需要更清楚的主题表达，但新增口播规则的触发边界过宽，导致含有人像和五官的生活方式样本被误判为口播场景。

[事实] 当前输出没有稳定形成“状态 / 场景 + 具体主题”的随手拍标题机制，也没有给出生活拼图、留白区和主题任务补足建议。

[推断] 下一步应立即修正两个点：

1. 收紧 `talking-head` 口播场景识别，要求同时出现口播 / 镜头 / 自媒体 / 剪辑等明确口播信号，不能只因“人物、五官”触发。
2. 新增 `lifestyle-snapshot` 随手拍场景，补“生活感 + 主题任务 + 轻标题 + 留白 / 拼图叙事”的方向、标题和构图规则。
