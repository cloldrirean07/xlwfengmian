## 6. 结论

[事实] 当前 MVP 已具备美食素材基础识别能力，也能给出“更有收获感 / 更有冲击力”的相近方向。

[事实] 当前规则会把 `mvp-ref-005` 美食教程合集样本偏向 `food-impact` 单图强冲击规则，导致标题和构图过度围绕红油、海鲜和食物近景。

[推断] 下一步应新增 `food-tutorial-collection` 场景，与既有 `food-impact` 分流：

1. 当输入包含家常菜、下饭菜、减脂餐、空气炸锅、菜谱、九宫格、多宫格、合集、数量感、收藏等信号时，优先识别为美食教程合集。
2. 标题机制应补为“数量 + 强评价 + 场景”，例如“9 款下饭菜封面先看这一版”“家常菜合集这样做更想收藏”。
3. 构图策略应补九宫格 / 多宫格、中央横条、上方大字、上下双标题和标题不遮挡食物主体。
4. 风险提醒应强调不机械套数量、不只写好吃香馋、不把单菜教程硬做成九宫格。
