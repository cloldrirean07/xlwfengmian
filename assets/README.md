# Assets

This folder stores visual materials used during product building and validation.

## Subfolders

- `references/`
  Inspiration captures, benchmark covers, and labeled examples.
- `screenshots/`
  Product screenshots, experiment records, and UI verification captures.
- `generated/`
  AI-generated outputs, mock covers, and test results.
- `raw/`
  Unprocessed source images, imported materials, and temporary inputs worth keeping.
