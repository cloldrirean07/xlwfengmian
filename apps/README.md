# Apps

This folder stores runnable product surfaces.

## Subfolders

- `web/`
  The main MVP workspace.
  This is where current feature logic, scripts, tests, and static frontend files live.
- `admin/`
  Reserved for future internal tools, review panels, or operations dashboards.

## Rule

If something must run in a browser, be tested, or be released as part of the product, it should live under `apps/`.
