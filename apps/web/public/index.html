02 补齐人工确认

在 Obsidian 预览文档中填写人工结论、确认字段、仍需手改和写回判断。

03 检查写回状态

读回最新安全预览，确认人工结论有效且仍需手改为空。

04 执行正式写回

门禁满足后再覆盖真实批次记录，并生成规则修订与关键样例复跑任务。

UI Readiness Gate

UI 优化进入条件报告

用于判断当前是否已经积累足够真实批次证据，是否值得进入主链路 UI 优化讨论。

生成报告后将展示 UI 讨论时机、证据覆盖度和主要风险。

Cross-Batch Signals

跨批次摩擦点汇总

用于横向比较已导出的多批次试跑记录，识别重复摩擦点和更值得进入 UI 讨论的稳定问题。

生成汇总后将展示最常重复的摩擦点类别、推荐动作和 UI 讨论时机。

Review Dashboard

批次复盘看板

用于汇总最近人工结论覆盖状态、跨批次重复信号和 UI 时机判断，并形成下一批优先补齐项；正式复盘材料可通过复盘套件一次性导出。

生成看板后将展示当前最该补的批次、人工复盘趋势和 UI 讨论缺口。
