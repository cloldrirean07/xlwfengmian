# Prototypes

This folder stores prototype files and exported interaction drafts.

## Subfolders

- `wireframes/`
  Rough page structures and low-fidelity concept layouts.
- `flows/`
  User paths, interaction journeys, and step-by-step decision flows.
- `hi-fi/`
  Higher-fidelity mockups, polished screens, and exported design assets.
- `tests/`
  Prototype test notes, click-path validation captures, and usability feedback artifacts.
