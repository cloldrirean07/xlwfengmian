# Data

This folder stores structured data used by the product, not long-form documents.

## Subfolders

- `rules/`
  Rule tables, effect classifications, and reusable structured logic inputs.
- `cases/`
  Labeled case samples, annotated examples, and small training or evaluation sets.
- `feedback/`
  User feedback phrases, mapped adjustment signals, and refinement dictionaries.
- `experiments/`
  Experiment inputs, evaluation sets, and structured validation datasets.
